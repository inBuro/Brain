# Competitor SWOT — Screenshotter

Семь конкурентов: пять из быстрого ресёрча, два — новые находки из deep research
(Screentack, pxpipe). S/W — про сам конкурент, O/T — что это значит для нас, отдельно
по обеим гипотезам: **план A** (текущая концепция — платный menu-bar ресайзер, $20) и
**план B** (пивот — менеджер контекста/точности для AI-агентов, MCP).

## LazyScreenshots

- **S:** Уже занял позицию «screenshot tool for AI coding», авто-вставка убирает
  весь ручной шаг, отработанная модель разовой покупки $29.
- **W:** По данным deep research — стагнация интереса, вытесняется MCP-инструментами;
  нет токен-экономики, только удобство ввода.
- **O:** (A) Его стагнация освобождает узнаваемость категории — можно зайти дешевле и
  проще. (B) Тот же вакуум работает в пользу MCP-подхода ещё сильнее.
- **T:** Уже есть бренд-узнаваемость в нише «AI screenshot tool» — сложнее пробиться
  даже при более низкой цене.

## Image Resizer for Claude Code

- **S:** Бесплатный, open-source, 100% client-side, формулирует боль дословно как в
  нашем брифе («stops oversized Retina images from breaking sessions»).
- **W:** Не нативное приложение — Cloudflare Worker + веб-страница, требует ручного
  деплоя, не системный хоткей.
- **O:** (A) Наш нативный menu-bar UX — реальный, проверяемый дифференциатор против
  него: нет шага «открыть вкладку/задеплоить воркер».
- **T:** (A) Полностью бесплатная альтернатива, решающая ровно ту же задачу, снимает
  большую часть аргумента «плати $20».

## SlimSnap

- **S:** Радикальное решение — JSON вместо картинки (~700 токенов против 1500–4000 у
  сырого изображения), бесплатен, высокий вирусный охват, есть MCP-коннектор.
- **W:** Требует поддержки со стороны Claude Code skill/конфига — не работает «из
  коробки» в произвольном AI-чате, не универсален.
- **O:** (B) Прямое подтверждение спроса на решение глубже, чем ресайз картинки —
  обосновывает пивот в сторону контекст-менеджмента.
- **T:** (A и B) Забирает самых технически продвинутых пользователей — ровно нашу
  вероятную аудиторию ранних адоптеров.

## CleanShot X

- **S:** Зрелость, огромный набор фич, рыночный лидер, уже установлен у части
  аудитории.
- **W:** AI-контекст-боль не first-class сценарий вообще; платный ($29 + $8/мес
  Cloud Pro).
- **O:** Не прямой конкурент по JTBD ни в A, ни в B — конкурирует за место в
  меню-баре и за кошелёк, не за задачу.
- **T:** Ресурс и охват таковы, что может добавить AI-ориентированный ресайз одним
  апдейтом и закрыть нишу A мимоходом.

## Shottr

- **S:** Бесплатно бессрочно, легковесно (2.3 МБ), быстро.
- **W:** AI-боль не решает вообще, общего назначения.
- **O:** Как и CleanShot — не прямой конкурент по JTBD.
- **T:** Бесплатная привычная альтернатива снижает саму готовность платить за узкую
  утилиту в принципе, независимо от A/B.

## Screentack (новый, из deep research)

- **S:** MCP-сервер с 12 инструментами для агента, spatial manifest, прямой конкурент
  LazyScreenshots, активно растёт.
- **W:** $29, требует настройки MCP — выше порог входа, избыточен для тех, кому нужен
  просто лёгкий скриншот.
- **O:** (B) Валидирует направление — рынок уже реально движется к MCP-интеграции,
  это не гипотеза, а растущий сегмент.
- **T:** (B) Если пивотимся в B — это уже занятая и растущая ниша «MCP screenshot
  tool», не пустое поле.

## pxpipe (новый, из deep research)

- **S:** Open-source, обратная идея (текст → PNG для экономии токенов Claude Code),
  высокий резонанс на GitHub.
- **W:** Узкая механика — не про скриншоты экрана, а про упаковку текстового
  контекста; не прямой функциональный конкурент.
- **O:** Показывает, что open-source в этой аудитории заходит сильно — аргумент в
  пользу варианта Gemini «A: open-source вместо продажи».
- **T:** Конкурирует за внимание той же аудитории «token economy tooling для Claude
  Code» — если уже стоит pxpipe, дальше могут не искать.
