## Техпроверка: реально ли получить данные о контексте сессии (2026-08-21)

Вопрос возник из скепсиса Стаса к «адаптивной эскалации» — у продукта нет доступа к
внутреннему бюджету токенов модели. Проверка по каждой целевой поверхности:

- **Claude Code (CLI)** — да, точные данные. Statusline API отдаёт JSON с
  `context_window.used_percentage`/`remaining_percentage` после каждого хода; локальные
  transcript-файлы `~/.claude/projects/<project>/<session-id>.jsonl` несут точный
  `message.usage` (input/output/cache tokens) по каждому сообщению.
- **Cursor** — нет стабильного публичного API. Чат хранится локально в SQLite
  (`state.vscdb`), но это недокументированная схема; сами пользователи Cursor просят
  такую фичу как feature request. Парсинг возможен, но хрупок и ломается при апдейтах.
- **ChatGPT / Claude.ai (веб)** — недоступно. OpenAI намеренно скрывает заполненность
  контекста; сторонние расширения (ChatGPT Token Counter и т.п.) лишь считают токены по
  видимым сообщениям, не зная истинный бюджет (системный промпт/тулы не видны) — это
  оценка, не факт.

**Вывод (решение пользователя, 2026-08-21):** обещание, честно работающее только на
одном инструменте из нескольких целевых (Claude Code, Cursor, ChatGPT), — это не
универсальное решение, а избирательно нарушенное обещание. «Адаптивная эскалация по
росту сессии» удалена из скоупа как общая фича. Взамен — статический калькулятор
стоимости снимка (не требует доступа к сессии, работает везде одинаково), а точный
Claude-Code-специфичный остаток контекста остаётся только как явно промаркированный
нишевый бонус, не как продаваемое обещание продукта.
