# Приоритизация (MoSCoW) — Screenshotter

Два трека приоритизированы отдельно — у них разные primary-персоны и разный JTBD.
Плюс один кросс-трек пункт, который гейтит жизнеспособность обоих.

## Кросс-трек (решить до старта любого трека)

| Приоритет | Фича |
|---|---|
| **Must** | Модель распространения: donation/open-source вместо one-time лицензии $20 — обе персоны, тестировавшие цену (Оля, Женя), отвергли разовую покупку без пробы |

## Трек A — менюбар-ресайзер (primary: Оля)

| Приоритет | Фича | Критерий |
|---|---|---|
| Must | Два режима размера (уже есть) | JTBD напрямую, table stakes |
| Must | Индикатор активного режима до/во время захвата | Без него основной сценарий (уверенность, что сессия не упадёт) невозможен — подтверждено интервью |
| Must | Развести дефолтный хоткей с системным | Table stakes / предотвращение путаницы, Major из аудита |
| Must | Простой счётчик «скриншотов за сессию» | JTBD Оли оказался сессионным, не пофайловым — без этого обещание не выполняется |
| Must | Free trial / free tier | Без пробы конверсия невозможна (интервью) |
| Should | Автоопределение целевого приложения / авто-подбор режима | Важно, но ручной режим уже работает как fallback |
| Should | Объяснение ограничения shadow-тумблера | Улучшает доверие, не блокирует основной сценарий |
| Won't (now) | Адаптивная эскалация сжатия по росту сессии | Техпроверка 2026-08-21: честно работает только для Claude Code, не универсально — удалено из скоупа, см. `features_list.md` |
| Won't (now) | MCP-интеграция | Это Track B, не A |
| Won't (now) | PII redaction | Не запрошено ни одной персоной трека A |

## Трек B — контекст-менеджер для агентов (primary: Стас)

| Приоритет | Фича | Критерий |
|---|---|---|
| Must | Локальный / self-hosted MCP-сервер | Dealbreaker без этого — подтверждено интервью прямым текстом |
| Must | Нормализация под Computer Use (1024×768/1280×720) | Прямое попадание в JTBD («промахи курсора») — подтверждено, table stakes для этого сегмента |
| Must | Явный дифференциатор от Screentack | Без него нет причины выбирать нас, а не уже растущего конкурента |
| Must | Free trial / free tier (или сразу open-source) | Как и в треке A — цена без пробы не конвертирует |
| Should | Статический калькулятор стоимости снимка в токенах (по формулам платформы, без доступа к сессии) | Уникальная фича рынка, честно универсальна — работает на любой платформе одинаково |
| Could | Точный остаток контекста сессии — только Claude Code, явно промаркировано | Техпроверка 2026-08-21: точные данные (statusline API, `.jsonl` транскрипты) есть только у Claude Code; для Cursor нет стабильного API, для ChatGPT/Claude.ai недоступно вовсе. Нишевый бонус, не общее обещание |
| Should | Разрешение гонки ручного/агентского запроса | Важно для надёжности, не блокирует первый релиз |
| Could | Выбор монитора/окна | Edge case, не блокирует MVP |
| Could | Локальная деперсонализация PII | Незакрытый рыночный запрос, не запрошено самим Стасом |
| Won't (now) | Адаптивная эскалация сжатия по росту сессии как общее обещание | Честно работает только для Claude Code — оставлять как продаваемую фичу нечестно по отношению к пользователям других IDE-агентов |
| Won't (now) | Облачный SaaS-вариант | Явно отвергнут интервью |
| Won't (now) | Авто-вставка в чат | Не входит в JTBD Стаса (это фича трека конкурентов вроде LazyScreenshots) |
