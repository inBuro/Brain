# Каталог директив

Одна строка на директиву: в какой момент за ней тянуться и что остаётся после. Вызов — по имени файла: «выполни директиву `directive_personas`». У большинства есть воркфлоу-обёртка в [`../workflows/`](../workflows/_catalog.md), тогда проще запускать слэш-командой.

Устройство жанра, отличие от скилла и история — в [README.md](README.md).

## Общего назначения

| Директива | Когда звать | Остаётся |
| --- | --- | --- |
| `directive_builder.md` | процедуру повторяешь третий раз по памяти | новая директива + строка в README |
| `directive_recursive_briefing.md` | есть хотелки заказчика, нет задачи | `brief.md` — пользователи, функциональность, ограничения, открытые вопросы |
| `directive_youtube_outreach.md` | накопились комментарии под видео Fadercraft | черновики ответов; живёт и как скилл `fadercraft-youtube-outreach` |
| `parity_check.md` | код и Figma подозрительно разошлись | read-only отчёт по расхождениям |
| `figma_mcp_setup.md` | агент не видит Figma | подключённый MCP |
| `connect_notion_mcp.md` | агент не умеет писать в Notion | подключённый MCP |
| `directive_skills_architect.md` | скиллов много и они дублируют друг друга, пора пересобрать среду в систему групп | группы-мультискиллы, роутеры, слои правил/принципов, протокол онбординга; вызывается по имени, но с 2026-08-28 та же методология также живёт как скилл `skills-architect` с автовсплытием (см. историю жанра в README) |

| Директива | Когда звать | Остаётся |

## Курс: документ в экраны (модуль 2)
