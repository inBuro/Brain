# workflows

Documented multi-persona sequences — cases where a task needs more than one agent from the registry in one flow (e.g. `project-manager` synthesizes a launch result, hands the read to `copywriter` to update landing copy). The router (`../../CLAUDE.md`) already tells the user this case belongs in a `~/Brain` session using the Task-tool orchestrator-workers pattern, not something the folder-router does itself — files here would document *which* sequences are common enough to name, not implement them.
