# Какие модели для чего нужны

Выдержка из урока 3.2 «Как устроены генеративные модели» (10:46, теория, без домашки).
Полный конспект с тайм-кодами — `../notes/m3-02-generative-models.md`.

## Два типа архитектур

**Диффузионные** (Flux, Stable Diffusion, Midjourney)
- Старт из шума → формы → структура → изображение
- Генерируют не конкретное, а правдоподобное — обучены на пиксельных паттернах, не на смыслах
- Сильные стороны: фотореализм, природа, текстуры, материалы, освещение, художественный вкус, стилизация
- Слабые стороны: текст на изображении, сложные многоусловные инструкции, нереалистичные сцены, удержание контекста (каждая генерация с нуля, дорисовать по месту нельзя)

**Гибридные авторегрессивные** (Nano Banana Pro/2, GPT Image)
- Внутри языковая модель + визуальный движок, генерация поэтапная, с удержанием контекста
- Сильные стороны: точность, текст на изображениях (GPT Image — почти безошибочно на любом языке), следование промпту, многошаговое редактирование
- Нюанс: при большом числе условий приоритет достаётся первым, последние могут потеряться
- Слабые стороны: разрешение скромнее, художественный вкус посредственный (стиль нужно описывать подробно), скорость ниже — модель «думает» по этапам

## Открытые веса vs проприетарные

- Открытые веса — можно скачать, дообучить, гонять локально; дешевле в агрегаторах, но слабее
- Локальный запуск — сборки на 40–50 ГБ, машина занята целиком; оправдан при конфиденциальных данных и больших паках ассетов
- Проприетарные — лидеры рынка. Midjourney стоит особняком: доступен только через свой сайт и Discord, ни в один агрегатор не отдаётся

## Четыре способа доступа к моделям

1. Облачный SaaS
2. API через провайдеров (для разработки)
3. Локально на своём GPU
4. Гибридный агрегатор вроде Krea

## Карта решений: какую модель под какую задачу

| Задача | Модель |
| --- | --- |
| Фотореализм и художественный визуал | Диффузия (Flux 2 Pro, Midjourney) |
| Текст на изображении, инфографика, многоязычные баннеры | Гибрид (Nano Banana, GPT Image) |
| Многошаговое редактирование и удержание персонажа | Гибрид |
| Уникальный персонаж | Связка: сначала Midjourney за красивый исходник → потом гибрид на доводку |
| Кастомный стайл-пак под бренд с дообучением | Диффузия + гибрид, необязательно локально — те же ноды доступны в Krea и Weave |
| Повседневные эксперименты и быстрые превью | Krea как универсал |
