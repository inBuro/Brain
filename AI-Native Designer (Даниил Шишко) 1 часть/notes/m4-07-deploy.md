# 4.7. Публикация и деплой — 10:33

| Тайм-код | О чём |
| --- | --- |
| 0:00 | **Путь A — готовый сервис** (Vercel, Netlify, Cloudflare): подключаешь репозиторий, сервис сам собирает и пересобирает после каждого пуша. Всё в браузере |
| 0:50 | Минус: лимиты бесплатных тарифов и **нестабильное открытие таких ссылок из России** |

| 2:10 | Коммерция: Vercel на бесплатном запрещает (только тесты и портфолио), Netlify и Cloudflare разрешают |
