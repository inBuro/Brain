# 3.4. Анатомия промпта — 11:04

Промпт пишется в одно поле, но модель всегда различает внутри него пять смысловых слотов.
Не управляешь слотами — модель додумает их за тебя.

| Тайм-код | О чём |
| --- | --- |
| 0:00 | Два нюанса урока: слоты внутри одной фразы и формат записи, разный под разные архитектуры |
| 0:40 | **Слот 1 — субъект**: кто или что в кадре. Якорь, на который модель навесит остальное; без него промпта нет |
| 1:00 | **Слот 2 — стиль**: эстетика, техника, стилистические референсы. Задаёт визуальный язык всей картинки |
| 1:17 | **Слот 3 — окружение**: локация и фон. Без него субъект выходит скучным |
| 1:35 | **Слот 4 — детали**: самый длинный слот, здесь живёт уникальность сцены |
| 1:50 | **Слот 5 — технические параметры**: ракурс, свет, формат, разрешение, объектив |
| 2:10 | Приём: не можешь описать, почему кадр красивый, — назови камеру или плёнку, модель сама достанет стиль из обучения |
| 2:33 | Приём с референсами: искать под каждый слот отдельную картинку и заряжать их мульти-референсом — субъект с одной, стиль со второй, окружение с третьей |
| 3:00 | Разбор промпта по слотам на живом примере (фигура на краю скалы, золотой час, 13 мм, 16:9) |
| 3:51 | Проверка: заполнены все слоты → повторные генерации дают почти одинаковый результат, то есть контроль реальный |
| 4:00 | **Главное правило — конкретность.** «Красивый», «качественный», «современный» не несут информации |
| 4:20 | Почему: представление модели о «крутом премиальном» осталось на уровне старых изображений — кожа и золото. Старых картинок в обучении всегда больше, чем свежих |
| 5:06 | Как чинить: каждое оценочное прилагательное — упущенный шанс на конкретику. «Красивый закат» → оранжево-розовый градиент, силуэт, перьевые облака |
| 5:40 | Тот же приём для UI: не «красивая иконка», а плоская монохромная, обводка 2 px, мягкие скругления |
| 6:00 | **Порядок слов важен**: модель читает сверху вниз, сильнее всего влияет начало. У диффузионных заметно резче, у авторегрессивных мягче. Главное — в первой трети |
| 6:29 | **Тег-формат для диффузионных** (Midjourney, Stable Diffusion): ключевые слова через запятую, веса через двоеточие (`rock:2`, `ocean:0.5`), технические параметры флагами (`--ar 16:9`) |
| 7:51 | **Описательная речь для гибридных** (Nano Banana, GPT Image): длинные предложения с условиями работают лучше тегов, модель воспринимает их как инструкцию |
| 8:30 | **Flux 2 — пограничный**: диффузия с продвинутым языковым энкодером, читает оба формата. Но и стилистика ниже Midjourney, и контроль ниже гибридов |
| 9:08 | Ещё отличие: с гибридной моделью можно продолжать диалог и дорабатывать, с Midjourney — только переписывать промпт и надеяться |
| 9:40 | **Когда промпта достаточно**: разовые задачи, поиск стиля, быстрая проверка идеи |
| 10:00 | **Когда перестаёт хватать**: серии в одном стиле, воспроизводимость через месяц, командная работа. Отсюда переход к JSON |
