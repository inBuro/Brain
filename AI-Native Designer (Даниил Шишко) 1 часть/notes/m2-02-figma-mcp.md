# 2.2. Подключение Figma MCP — 10:15

Технический урок: MCP как протокол между агентом и Figma, выбор сервера, установка, лимиты.

| Тайм-код | О чём |
| --- | --- |
| 0:00 | MCP — открытый стандарт, по которому агент общается с внешними инструментами (Figma, Notion) |
| 0:47 | Два варианта сервера — Desktop и Remote; выбор определяет, что агент вообще сможет делать |
| 1:00 | Desktop: поднимается локально из Figma Desktop → DevMode → Enable Desktop MCP Server. Умеет читать контекст, переменные, стили, Code Connect, но **создавать и менять объекты на канвасе не может** — вариант для разработчика |
| 2:31 | Remote: хостится Figma на `mcp.figma.com`, авторизация в браузере, десктоп-приложение не нужно. Даёт `use_figma` — весь write-функционал. В модуле берём его |
| 3:00 | Четыре группы возможностей: чтение структуры (вся иерархия, включая переменные внутри вариантов компонента), запись на канвас, FigJam, Code Connect |
| 3:25 | Имена инструментов запоминать не нужно — агент сам подбирает под задачу |
| 4:17 | Code Connect — маппинг Figma-компонентов на код в репозитории, чтобы правка в Figma не расходилась с продом; разбирается в четвёртом модуле |
| 5:04 | Установка по директиве: агент правит конфиг, затем просит перезапустить расширение и написать «готово» |
| 6:36 | Дальше — прислать ссылку на любой фрейм. Если расширение не перезапущено, агент честно скажет, что подключение не поднялось |
| 7:21 | Первый вызов триггерит OAuth: **авторизоваться именно оплаченным аккаунтом Figma**, не бесплатным основным |
| 8:07 | **Требование к плану**: нужен Dev или Full seat. На Starter seat write-функционал MCP не работает, только чтение. Dev/Full есть на любом платном плане |
| 8:30 | Где брать: Figma Education бесплатно для студентов, иначе купить подписку на полгода по ссылке под уроком; в командном аккаунте обычно уже есть |
| 8:52 | **Лимит Pro-плана — 200 MCP-запросов в день**. Хватает, если не слать каждую мелкую правку отдельной командой |
| 9:10 | Правило батчинга: не «переименуй слои», «примени Auto Layout», «убери пустые группы» тремя запросами, а один пул правок |
| 9:38 | Домашка: подключить MCP и попросить агента описать, что он видит в макете |
