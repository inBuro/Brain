# 3.6. Midjourney — карта инструмента и сборка собственного стиля — 32:07

Обзорно-демонстрационный урок: повторять всё не обязательно, задача — забрать карту, где что лежит.

| Тайм-код | О чём |
| --- | --- |
| 0:00 | Природа инструмента: сильна вкусом, слаба в точных инструкциях и мелком тексте. Работает по принципу «я художник, я так вижу» — даже указание «в правой части кадра» может проигнорировать |
| 1:00 | Отсюда типовой сценарий: визуал забирают отсюда и правят в других моделях |
| 2:01 | Исторически жил в Discord, сейчас основное — веб-приложение; Discord остался, но смысла в нём нет |
| 2:20 | **Explore** — лента чужих работ и стилей, фильтры и сортировки, главный источник вдохновения |
| 3:00 | **Create** — генерация; видео здесь скорее анимация имеющегося, а не полноценная генерация |
| 4:03 | Настройки: **Aspect Ratio** (интерфейс сам дописывает `--ar` в промпт) |
| 4:40 | **Модель**: у каждой версии свой набор фич. В V7 есть OmniReference, в 8.1 его нет |
| 5:30 | Честная оценка OmniReference: следует ему примерно одна генерация из десяти |
| 6:05 | **RAW против Standard**: RAW чище и реалистичнее, Standard даёт фирменный визуал — его и берут по умолчанию |
| 6:30 | **Stylization**: 100 — норма, 450–500 — заметно больше стиля, выше — уже непредсказуемо. Для фотореализма: RAW + стилизация в ноль |
| 7:00 | **Weirdness** — креатив в композиции, отход от ожидаемого. Автор им обычно не пользуется |
| 7:30 | **Variety** — насколько разными будут четыре изображения в пачке. Полезно, пока ищешь визуал |
| 8:06 | **Fast против Relax**: на подходящем тарифе relax-очередь безлимитная |
| 9:00 | Генерация всегда идёт пачкой по четыре; в подписи видно, какие флаги были добавлены |
| 9:40 | Наблюдение: за приложенным Style Reference модель следует небрежно |
| 10:06 | **Вариации Subtle и Strong**: subtle сохраняет композицию и меняет мелочи, strong меняет позу, стиль и раскладку кадра |
| 11:00 | Действия над готовым кадром: Rerun с теми же вводными, Edit, Run as HD, вытащить из него Style Reference одной кнопкой |
| 12:10 | **Анимация**: режим Auto (финальный кадр отличается от стартового) и **Loop** (бесшовный цикл для лендинга), плюс Low и High Motion |
| 13:00 | Loop работает не всегда — стык бывает виден по цветокору, приходится перегенерировать |
| 14:12 | **Edit**: маска через Paint или Smart Select, дальше in-paint. Модель креативит вместо точечной правки |
| 15:20 | Живой пример: заменить тарелку на статуэтку — четыре вариации мимо. На V7 результат ближе к запросу, чем на 8.1 |
| 16:12 | Retexture — фактически те же вариации; автор смысла в нём не видит |
| 16:30 | **Три способа собрать свой стиль**: Personalize, Mood Boards, Style Creator |
| 16:50 | **Personalize**: выбираешь пары изображений, пока не заполнится шкала — модель учится твоему вкусу |
| 18:17 | **Предупреждение**: лента подстраивается под выбор. Автор выбрал пару мрачных кадров ради стилистики и получил ленту соответствующей тематики |
| 19:00 | Практика: базовый профиль вкуса на старте, отдельные профили под конкретные проекты и задачи |
| 20:20 | Сравнение с персонализацией и без: без неё кадры базовые, с ней меняются цветокор, обработка, композиция |
| 21:00 | **Mood Boards**: то же самое, но из своих загруженных изображений. У каждого борда свой код, который подставляется в промпт |
| 21:40 | **Style Creator**: задаёшь тему, выбираешь из вариаций на одной композиции, пока не пройдёшь порог «идеал минимум», затем End session |
| 23:00 | Дальше из удачных генераций собирается мудборд — и новые запросы идут уже в этой стилистике |
| 24:25 | **Чужие стили из Explore**: профиль автора копируется в промпт и переиспользуется как есть |
| 25:40 | **Язык промпта**: лучше английский. На русском модель добавляет региональный колорит — «инженер» превращается в свитер из 90-х, а в кадре появляется кириллица |
| 26:28 | Главный аргумент за Midjourney: по короткому промпту получается кадр, которого не выжать из Nano Banana или GPT Image длинным описанием |
| 28:28 | Сводка параметров: Aspect Ratio, стилизация, chaos, weirdness, RAW, **Negative Prompt** (`--no dogs`), `--sv N` для серии больше четырёх, Style Weight |
| 29:40 | **Тарифы**: Basic $10, Standard $30, Pro $60, Mega $120. Расходуются не токены, а часы генерации |
| 30:31 | **Рекомендация — Standard**: 15 часов быстрой генерации (более тысячи изображений) плюс безлимитная relax-очередь |
| 31:20 | Оговорка: на Standard генерации публичны, чужой человек может забрать твою стилистику. Приватность — только на Pro |
| 31:50 | Домашка без проверки: собрать персонализацию или один стиль через Style Creator и поглядеть, как меняется визуал |
