# 3.7. Krea — мульти-инструмент модуля — 31:54

Философия противоположна Midjourney: под одной подпиской десятки моделей, ноды, обучение LoRA,
real-time canvas, edit, апскейл. Midjourney опционален, Krea — обязательна.

| Тайм-код | О чём |
| --- | --- |
| 0:00 | Позиционирование: в Krea можно делать всё, включая то, что делает Midjourney, но не на том же уровне |
| 2:05 | **Home** — поиск и мудборды, интерфейс в духе Pinterest, удобнее, чем в Midjourney |
| 2:40 | Совет при сборке мудборда: держаться одной стилистики, а не собирать всё подряд — модели проще воспроизвести |
| 4:06 | Собранный борд сам предлагает похожие изображения для добора |
| 4:30 | **Analyse Board** — агент описывает вкус, ключевые слова и гайдлайны борда; при генерации они подставляются автоматически |
| 5:00 | **Ключевое ограничение: мудборды работают только с внутренними моделями Krea.** У Nano Banana их нет |
| 5:30 | Настройки почти как в Midjourney: style strength, креативность (аналог weirdness), рандомность |
| 6:11 | Честная оценка результата: до красоты исходного мудборда генерации не дотягивают |
| 7:00 | **Важный дефект**: при style strength на 100 модель тянет к референсам не только стиль, но и сами объекты — бутылка Coca-Cola искажается. Так быть не должно, но так работает |
| 8:12 | При style 0 и максимальной креативности форма объекта держится лучше, но от мудборда мало что остаётся |
| 8:30 | **LoRA против мудбордов**: мудборд — это референсы, LoRA — настоящее обучение, модель ищет взаимосвязь между изображениями. Результат заметно консистентнее |
| 9:20 | Обучение: Train New LoRA → изображения или видео → 10–20 картинок из библиотеки или своих |
| 10:12 | **Выбор базовой модели**: Krea для стильного визуала, Flux для точного следования. Wan, Qwen, Z-Image — сомнительно, начинать с них не стоит |
| 10:40 | Оптимизация под назначение: style, object, character или default. Лучше выбрать конкретное |
| 11:00 | **Learning rate**: слишком высокий — модель будет буквально копировать исходники. 0.004 по умолчанию — оптимум |
| 11:40 | Стоимость обучения в токенах растёт вместе с числом шагов и качеством — прямая корреляция |
| 12:13 | Генерация в своей LoRA: ползунок силы следования, промпт лучше на английском |
| 13:20 | Скорость и цена внутренних моделей: 6 токенов и несколько секунд при лимите 20 000 токенов на тарифе Pro |
| 13:50 | **Style Transfer** как замена LoRA, когда некогда обучать: тот же промпт даёт заметно худшую консистентность — цветокор уезжает |
| 14:14 | Типовые артефакты дешёвых быстрых моделей: отваливающиеся предметы, пальцы, лица, зловещая долина на повторяющихся деталях |
| 16:15 | Почему LoRA в Krea — киллер-фича: обычно это история локальной работы с 50-гигабайтными моделями, а здесь браузер и 6 токенов |
| 17:00 | **Node Editor** упоминается вскользь: параллельная генерация одного промпта в Nano Banana и ChatGPT. Гибридные модели в нодах дороже внутренних |
| 18:17 | **Выбор модели в Image**: Nano Banana 2 — точные правки; GPT Image — текст; Nano Banana Pro — точнее, но менее креативна и медленнее; Krea — креативная диффузия; Flux 2 — компромисс |
| 19:40 | Остальные (Imagen, Z-Image, Seedream) — ситуативно: хайпуют, но мастодонтов не догоняют |
| 20:20 | **Real-Time Editor**: композиция из каракулей, готовых картинок и 3D-моделей, генерация на лету |
| 22:28 | Оговорка: работает отдельная модель Real-Time Edit — быстро, но неточно. Это инструмент наброска, не финального визуала |
| 24:30 | **Edit**: AI Edit ничем не отличается от обычной генерации в той же модели |
| 25:00 | **Критичный нюанс in-paint**: Nano Banana и ChatGPT не поддерживают честный in-paint — меняют область, но перегенерируют всё изображение (падает качество, плывёт геометрия, появляется дымка) |
| 26:41 | **Точечно работает только Flux InPaint** — при переключении не меняется ничего, кроме выделенного куска |
| 27:00 | Прочее в Edit: Annotate (указать объект словами), Crop и Expand (out-paint), Image Adjustments, Draw, Change Camera Angle (качество слабое — используется дешёвая модель) |
| 28:43 | Слабые разделы: Video Lipsync (для этого есть ElevenLabs и HeyGen), Motion Transfer, Video Restyle. 3D-объекты — неплохо, но без чудес |
| 30:00 | **Тарифы**: Free, Basic, Pro ($35), Max. **Брать Pro** — в нём ноды и 20 000 токенов, этого хватает на весь модуль |
| 30:43 | Домашка без проверки: мудборд из 10–15 изображений с Analyse Board, своя LoRA на 10–20 картинках, серия из 3–5 изображений в одной стилистике |
