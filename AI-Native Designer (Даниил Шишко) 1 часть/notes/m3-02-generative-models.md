# 3.2. Как устроены генеративные модели — 10:46

Теоретический урок без домашки. Смысл: архитектура определяет сильные и слабые стороны, а не маркетинг,
и это знание не устаревает — имена сменятся, архитектуры останутся.

| Тайм-код | О чём |
| --- | --- |
| 0:00 | Зачем дизайнеру архитектура: без неё выбор модели — угадывание, с ней задача сразу кладётся в нужную модель |
| 0:50 | **Диффузионные модели** (Flux, Stable Diffusion, Midjourney): старт из шума → формы → структура → изображение |
| 1:15 | Ключевое: модель не рисует конкретное, а генерирует правдоподобное. Обучена на пиксельных паттернах, а не на смыслах |
| 1:50 | Сильные стороны диффузии: фотореализм, природа, текстуры, материалы, освещение, художественный вкус, стилизация |
| 2:25 | Слабые: текст на изображении, сложные многоусловные инструкции, нереалистичные сцены — и **удержание контекста**: каждая генерация с нуля, дорисовать по месту нельзя |
| 3:35 | **Гибридные авторегрессивные** (Nano Banana Pro/2, GPT Image): внутри языковая модель + визуальный движок; генерация поэтапно с удержанием контекста |
| 4:10 | Сильные: точность, текст на изображениях (GPT Image — почти безошибочно на любом языке), следование промпту, многошаговое редактирование |
| 4:30 | Нюанс: при большом числе условий приоритет достаётся первым, последние могут потеряться |
| 5:00 | Слабые: разрешение скромнее, художественный вкус посредственный (стиль надо описывать подробно), скорость ниже — модель думает по этапам |
| 5:30 | **Открытые веса против проприетарных**: открытые можно скачать, обучить, гонять локально; дешевле в агрегаторах, но слабее |
| 5:57 | Локальный запуск: сборки на 40–50 ГБ, машина занята целиком. Оправдан при конфиденциальных данных и больших паках ассетов |
| 6:40 | Проприетарные — лидеры рынка. **Midjourney стоит особняком**: доступен только через свой сайт и Discord, ни в один агрегатор не отдаётся |
| 7:08 | Четыре способа доступа: облачный SaaS, API через провайдеров (для разработки), локально на своём GPU, гибридный агрегатор вроде Krea |
| 8:40 | **Карта решений.** Фотореализм и художественный визуал → диффузия (Flux 2 Pro, Midjourney) |
| 9:00 | Текст на изображении, инфографика, многоязычные баннеры → гибрид (Nano Banana, GPT Image) |
| 9:32 | Многошаговое редактирование и удержание персонажа → гибрид |
| 9:40 | **Уникальный персонаж → связка**: сначала Midjourney за красивый исходник, потом гибрид на доводку |
| 10:00 | Кастомный стайл-пак под бренд с дообучением → диффузия + гибрид, необязательно локально: те же ноды в Krea и Weave |
| 10:20 | Повседневные эксперименты и быстрые превью → Krea как универсал |
