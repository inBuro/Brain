# 2.10. Аудит и консистентность между экранами — 8:43

Директива `screens_audit` — единственная в модуле, которая **по умолчанию только читает**
и ничего не пишет в Figma и каталог без явной просьбы.

| Тайм-код | О чём |
| --- | --- |
| 0:00 | Любая ДС начинает разъезжаться, как только экранов больше двух — это нормально, ненормально копить расхождения незаметно |
| 0:30 | **Главный антипаттерн — «почти такие же, но чуть другие компоненты»**: через 10 экранов будет 10 слегка разных карточек, и никто не вспомнит, какая правильная |

| 1:20 | **Проверка 2**: все заливки, обводки и эффекты через переменные; цвет, выбранный из палитры руками, — баг |
| 1:48 | **Проверка 3**: дубликаты — два Component Set с похожими именами и анатомией, кандидаты на объединение |
