# 1.1-доп. Antigravity — среда для работы с агентами — 32:05

Дополнительный обзорный урок по средe, собран по вопросам студентов. Домашнего задания нет.

| Тайм-код | О чём |
| --- | --- |
| 0:00 | Что такое IDE и почему курс идёт в ней, а не в чате: файлы, терминал, браузер и агент живут в одном пространстве и видят друг друга |
| 1:31 | Сравнение сред. VS Code — универсальная, агент подключается плагином (Copilot, Claude Code), подписка отдельная. Cursor — заточен под агентов, $20/мес, лимиты нещедрые, за Claude придётся платить дважды |
| 3:02 | Claude Code как отдельное приложение: возможностей больше, но неудобно работать с текстовыми артефактами; через командную строку тоже неудобно |
| 3:30 | Почему выбран Antigravity: соотношение возможностей к цене — около 1000 ₽ за полгода, внутри и Claude Opus, и Gemini, плюс 2 ТБ хранилища, Deep Research, Nano Banana |
| 4:34 | Antigravity — продукт Google, напрямую из РФ не работает: нужен VPN и не-российский аккаунт. Покупать на аккаунт продавца; если на свой — не на основной, есть риск утечки |
| 6:10 | Почему свой сервер, а не готовый VPN-сервис: чужие IP палятся и отваливаются, и при сбое непонятно, что именно сломалось — Google, провайдер, роутер или среда |
| 7:41 | Тур по интерфейсу: Explorer, что такое `.md`, превью по правой кнопке, чат справа |
| 9:14 | Code Search — поиск по всем артефактам среды; Source Control, Run and Debug, Remote Explorer, Testing — для разработчиков, не нужны |
| 10:44 | Open Agent Manager — отдельное окно для диалогов с агентом по всем средам; минус: файлы можно смотреть и комментировать, но не править |
| 13:48 | Настройки: Strict Mode (подтверждение каждого действия), Auto Execution терминальных команд, белые и чёрные списки команд |
| 15:20 | Если Antigravity не запускается или не пускает по авторизации — скачать предыдущую версию (View Previous Releases); точную версию уточнять у продавца аккаунта |
| 16:52 | **Откат**: «Undo Changes up to this point» на своём сообщении возвращает состояние файлов на момент этого сообщения |
| 18:22 | Модели в списке: Gemini 3.1 Pro / High / Low / Flash, Sonnet, Opus. С Gemini можно диктовать голосом, с моделями Claude — нет |
| 19:55 | Что такое MCP простыми словами: без него агент не знает, как устроен Notion или Figma; MCP — связующее звено, которое объясняет модели правила приложения |
| 21:26 | Rules и **Workflow**: свой воркфлоу вызывается из чата через `/` и жёстко привязывает запуск к конкретной директиве — полезно, когда директив много и агент не угадывает нужную |
| 22:59 | Устройство агентского проекта: `GEMINI.md` (архитектура) → `directives/` (инструкции под задачи) → `.env` (ключи, никому не передаём) → артефакты. Артефакты можно складывать в отдельную папку, прописав это в `GEMINI.md` |
| 26:00 | Почему нужна архитектура: модель вероятностная, чем больше шагов делает сама, тем выше шанс ошибки — поэтому директивы, слои и скрипты |
| 26:30 | **Выбор модели**: Opus — лучший результат, но тяжёлый и быстро съедает лимит; Sonnet — почти не хуже, для многих итераций; Gemini Pro High — сопоставим с Opus, лимиты щедрее; Pro Low — повседневные задачи; Flash — черновики и мелкие правки |
| 29:04 | Итоговое правило: Opus → Sonnet → Gemini Pro High → Pro Low → Flash. Автор сам постоянно сидит на Pro High, лимиты выбрать сложно |
| 29:30 | Плагины: живой предпросмотр Markdown, Mermaid Preview, Error Lens, GitLens (подсветка правок агента и откат в клик), Todo Tree, DotENV, Code Spell Checker (опечатки провоцируют галлюцинации), Thunder Client, Project Manager |
| 31:00 | Antigravity собран на базе VS Code — любой плагин из библиотеки VS Code сюда ставится |
