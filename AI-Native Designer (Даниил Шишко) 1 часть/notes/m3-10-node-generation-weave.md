# 3.10. Принцип нодовой генерации + Figma Weave — 39:35

Самый длинный урок модуля. Весь модуль шаги делались поодиночке — нодовый подход собирает их
в один управляемый граф: выстроил пайплайн один раз, дальше прогоняешь сколько угодно.

| Тайм-код | О чём |
| --- | --- |
| 0:00 | Обычный промпт — чёрный ящик: на вход текст, на выходе картинка, внутри ничего не видно. Ноды раскладывают процесс по полочкам |
| 0:40 | Разбор живого графа: исходник → описание изображения через LLM → два разных out-paint → crop → upscale → compare |
| 2:22 | Смысл: любой шаг чинится в одном месте, а на вход можно подавать какое угодно изображение — дальше пайплайн отрабатывает сам |
| 3:00 | **Пять групп нод**: вход и утилиты (текст, изображение, crop, склейка — без ИИ), генерация (изображение, видео, текст, 3D), правки (in/out-paint, маски, свет, цвет), улучшение (апскейл), спецноды и вывод |
| 4:47 | **У любой ноды есть вход и выход.** В Weave: зелёный — выход, розовый — вход; фиолетовым идёт текст, зелёным изображение. В Krea цвета другие: жёлтый — текст, синий — изображение, розовый — переменные |
| 5:40 | **Выбор инструмента**: Krea — вкатиться (подписка уже есть, приятный UI), но часть нод не запускается и многих не хватает. Figma Weave — для серьёзной работы: нод больше, работает быстрее, меньше визуального мусора |
| 7:08 | В Krea есть агент, собирающий пайплайн по описанию через UI — полезно на старте, но лучше разбираться руками |
| 8:30 | Первая нода: Generate Image, выбор модели, видно стоимость в Compute Units |
| 9:30 | Промпт можно вынести отдельной нодой — удобно, когда правишь только текст, а весь пайплайн запускаешь одной кнопкой |
| 10:00 | Плюс Krea: нодовый редактор вписан в экосистему — мудборды, стили и enhancer из основного интерфейса доступны прямо в графе |
| 10:40 | Числовые параметры тоже выносятся отдельными нодами-переменными и раскидываются на несколько нод сразу |
| 11:53 | **Конкатенация** — объединение кусков текста в один промпт. Ключевой приём урока |
| 13:00 | Схема: статичная часть («generate … with the style:») зашивается в конкатенатор, меняется только нода с объектом — одно слово вместо правки JSON |
| 14:13 | Дальше JSON раскладывается по полям: style, mood, object — каждое отдельной нодой, кавычки и скобки живут в статичных кусках |
| 16:33 | **LLM Call как переводчик**: пишешь промпт по-русски, системный промпт ноды — «переводи на английский», дальше по графу идёт английский текст |
| 17:30 | Утилитарные ноды: Hue/Saturation, Upscale (Magnific — креативный, Topaz — точный, Krea Enhancer — дёшево) |
| 18:00 | **In-paint в нодах**: нужны две связи — изображение и **маска**. Маска рисуется в ноде Image Mask Editor и подаётся отдельно, иначе модель получит всё изображение с пятном |
| 18:53 | Результат: объект сгенерирован точечно и подогнан по перспективе; чтобы попал в стилистику, промпт достраивается конкатенацией |
| 20:00 | **Figma Weave**: 150 токенов бесплатно при регистрации — на домашку хватает; подписка от $24/мес для курсового |
| 21:14 | Нод очень много: уровни, каналы, альфа-маски, маски по тексту, 3D, модели комьюнити (работают не всегда) |
| 22:00 | **Практическая ловушка**: при перетягивании связи Weave сужает поиск и не показывает нужную ноду — искать через правый клик по имени |
| 23:00 | Out-paint в Weave: Flux (zoom out) и Stable Diffusion (по сторонам, с креативностью). Полезно подать описание изображения — есть готовая нода Image Describer |
| 23:34 | **Роутер** — утилитарная нода, собирающая пучок связей в один поток. На четырёх нодах незаметно, на двадцати без него граф превращается в кашу |
| 25:54 | Сравнение результатов: Stable Diffusion дорисовал аккуратно, Flux сильно накреативил |
| 26:30 | **Важно**: если внутри ноды несколько вариантов, дальше по пайплайну идёт именно выбранный |
| 27:00 | Ноды Crop и Preview (просто посмотреть результат), Compare — слайдер для сравнения двух вариантов |
| 28:16 | **Итераторы** — главный приём для серий. Text Iterator принимает список объектов, и пайплайн прогоняется по каждому |
| 30:39 | Стоимость считается сразу: два значения в итераторе → 12 кредитов вместо 6. Nano Banana в Weave заметно дешевле, чем в Krea |
| 32:59 | **Split text by**: перечисление через запятую автоматически разбивается на отдельные итерации |
| 33:30 | Полная автоматизация: LLM генерирует сам список объектов по теме, список уходит в итератор, итератор — в генерацию. Меняешь одно слово темы — получаешь новый пак |
| 35:19 | Результат — batch консистентных изображений в единой стилистике. Это и есть «конвейер бесконечных вариаций» |
| 36:30 | Где смотреть готовые пайплайны: главный экран Weave — генерация иллюстраций, смена угла камеры, преобразование в 3D |
| 37:41 | Оговорка: инструмент развивается, в чужих примерах встречаются рудименты и ноды без явного смысла |
| 38:30 | Домашка: собрать простой граф — нода с промптом, несколько нод генерации в разных моделях, апскейл лучшего варианта |
