# 3.3. Базовые подходы к генерации — 10:41

Вторая ось корневой теории. Домашки нет. Смысл: сначала выбираешь подход, потом под подход — модель,
а не наоборот. Карта работает на любых новых моделях.

| Тайм-код | О чём |
| --- | --- |
| 0:00 | Зачем запоминать именно формулировки: в одном инструменте механизм — это слайдер, в другом он спрятан, и найти его можно только зная название |
| 1:00 | Порядок решения: задача → подход → модель под этот подход |
| 1:20 | **Text-to-image**: промпт без входного визуала, режим по умолчанию везде |
| 1:50 | Когда брать: первый проход, нет исходника, арт-визуал, эксперименты со стилем |
| 2:10 | Когда не брать: есть визуал для доработки, нужна точная серия, нужно поменять одну деталь |
| 2:34 | Контроль самый низкий: композицию, ракурс и свет модель решает сама. Непредсказуемость полезна там, где нужен креатив |
| 2:50 | **Image-to-image**: исходник + промпт. Главный параметр — **denoising strength** (он же strength, image weight, control weight) |
| 3:20 | 0–40% — модель-помощник: лёгкая полировка, акценты освещения |
| 3:50 | 0.5–0.7 — модель-напарник, самый рабочий диапазон: стилизация, перенос стиля, обновление визуала |
| 4:05 | 0.8–1.0 — модель-художник по мотивам: исходник только структурная подсказка, композиция может уехать. Для грубого коллажа или скетча |
| 4:30 | Контроль над параметром есть не везде: Flux 2 в Krea даёт полный, Midjourney — фиксированные значения, Gemini с Nano Banana — вообще только через описание |
| 5:05 | **Reference-based**: несколько референсов, у каждого своя роль |
| 5:20 | **Ключевое отличие от i2i**: в image-to-image референс остаётся в кадре в переработанном виде, в reference-based он источник информации и в кадр не попадает |
| 5:40 | Style Reference (sRef): из референса берётся только стиль — палитра, текстура, атмосфера. Главный механизм для серии в одном стиле |
| 6:20 | Character Reference (cRef): удержание персонажа — пропорции лица, узнаваемые черты |
| 6:35 | Multi Reference: несколько ролей сразу. Flux 2 Pro принимает до 10 изображений — инструмент для жёстко контролируемых серий |
| 6:50 | Оговорка: один и тот же Flux в разных агрегаторах (Krea, Higgsfield, Weave) работает по-разному и непредсказуемо от дня ко дню |
| 7:20 | **In-painting**: маска на область, модель дорисовывает внутри неё. Убрать лишний объект или дорисовать деталь |
| 7:50 | **Out-painting**: дорисовка по краям под другой формат — 16:9 → 9:16, стиль и настроение удерживаются |
| 8:20 | Кто лучше: точечный in-painting — у ChatGPT; out-painting нетребователен, справляется Stable Diffusion быстро и почти без токенов |
| 8:40 | **Карта подходов**: с нуля → t2i, довести визуал → i2i, серия в одном стиле → reference-based, точечная правка и адаптация формата → in/out-painting |
| 9:20 | **Сквозной пайплайн**: t2i в Midjourney за креатив → i2i для вариантов и эталона → in/out-painting на доводку и форматы → апскейл |
