# 3.1. Что такое визуальная инженерия и что соберём в модуле — 8:07

Вход в модуль Visual Engineer. Домашки нет, но к следующему уроку нужны подписки.

| Тайм-код | О чём |
| --- | --- |
| 0:00 | Место на карте программы: модуль 1 — данные и PRD, модуль 2 — система в Figma, этот — визуал, следующий — код и деплой |
| 0:40 | **Главная идея модуля.** Обычный подход — «промпт-лотерея»: написал, подождал, не получилось — переписал. В личном эксперименте работает, в продакшене рассыпается |
| 1:04 | Почему рассыпается: нужна серия из десяти иконок в одном стиле, иллюстрации пустых состояний, баннер с текстом на трёх языках, продуктовый шот, повторяемый сто раз |
| 1:40 | Вторая беда лотереи — невоспроизводимость: через месяц не вспомнишь ни промпт, ни модель |
| 2:00 | Решение — относиться к визуалу как к пайплайну: задача → выбор модели → промпт → генерация → доработка → нодовая сборка → апскейл → результат. Каждый шаг повторяем, заменяем и запускается пакетно |
| 2:30 | Отсюда название модуля: дизайнер перестаёт быть оператором одной модели и становится инженером пайплайна |
| 2:45 | Структура модуля: сначала база, которая не устаревает, потом инструменты как примеры её применения |
| 3:09 | Четыре блока: корневая теория (архитектуры, подходы) → prompt engineering (пять слотов, JSON) → инструменты (Midjourney, Krea) → нодовая генерация |
| 4:10 | Нодовый блок собирает всё предыдущее в один воспроизводимый граф |
| 5:11 | **Минимальный стек**: Midjourney Basic $10/мес и Krea Pro $35/мес |
| 5:30 | Разделение ролей: Midjourney даёт стилистику из коробки, но почти без редактируемости; Krea даёт контроль и широту, но не тот стилистический пик. Одно без другого хромает |
| 6:18 | Опционально: Figma Weave (нодовый генератор сильнее, чем ноды Krea), ChatGPT Plus (точность), Google AI Pro (Nano Banana в чате Gemini) |
| 7:19 | Результат модуля: визуальный пак продукта в едином стиле, нодовый граф для переиспользования, понимание, как всё устроено |
