# 3.8. Апскейл — модели, настройки и пайплайн — 23:58

Диффузионные модели даже на высоких настройках отдают мягкое изображение, поэтому апскейл —
постоянный инструмент пайплайна, а не разовая операция.

| Тайм-код | О чём |
| --- | --- |
| 0:00 | **Четыре проблемы апскейла**: дорисованные детали, пластиковая кожа (или «чешуя») от недостаточной либо избыточной детализации текстур |
| 1:00 | **Сломанный текст**: универсального апскейлера, который вытянет и лицо, и фон, и текст, не существует — есть отдельные модификации под текст |
| 2:00 | **Изменённый бренд**: креативные апскейлеры меняют освещение, объекты и палитру |
| 2:20 | **Два типа**: faithful честно усиливает то, что есть; creative дорисовывает новое, придумывая, чем могло быть пятно |
| 2:40 | Инструменты: **Topaz** — faithful, **Magnific** — creative, **Krea Enhancer** — универсал, настраивается в обе стороны. У каждого есть подмодели противоположного типа |
| 3:50 | Krea Enhancer: кратность 2x достаточно для оценки; **Prompt** нужен, чтобы модель понимала, что на изображении — кнопка Describe может подтянуть не тот промпт, лучше описать самому |
| 5:00 | **AI Strength** — насколько дорисовывает. **Resemblance** — насколько честно держится исходника |
| 5:45 | **Clarity** — свобода менять цвет и освещение. **Sharpness** — резкость. **Match Color** — точное совпадение палитры |
| 6:30 | Ошибка №1 на живом примере: высокий AI Strength вместе с высоким Resemblance — модель зажата и выдаёт мыло |
| 7:00 | Ошибка №2: Resemblance в ноль — резкость отличная, но уезжают цвет, растительность, текст, появляются лишние объекты |
| 8:20 | **Рабочая комбинация**: AI Strength ~20%, Resemblance ~10%, немного Clarity, Sharpness по вкусу. Результат совпадает с исходником и при этом чёткий |
| 10:00 | **Главное правило**: не выкручивать ползунки в крайние значения — модель либо зажата, либо делает избыточную работу |
| 10:40 | Цена вопроса: Krea Enhance — 20 токенов, Topaz Generative и Bloom — 150–250 |
| 11:19 | **Magnific**: пресеты по типу контента (портреты, иллюстрации, видеоигры, фильмы), engine лучше оставить Automatic |
| 12:20 | Параметры Magnific: Creativity, HDR (может испортить), Resemblance, Fractality (детализация текстур) |
| 13:11 | **Topaz**: Sharpness, De-noise, Subject Detection (фон или передний план) и **Face Enhancement** — апскейлеры часто портят лица, эта галочка спасает |
| 14:00 | Результат Magnific на creativity 7–8: очень много деталей, но и артефакты — лишнее зеркало вместо спойлера, лишняя колёсная арка, новые шильдики |
| 15:02 | Почему так: диффузионная модель не думает, а воспроизводит нечто созвучное тому, что помнит |
| 17:00 | Результат Topaz: не так впечатляюще, зато ничего не удалено и не перемещено — честное повышение чёткости |
| 17:40 | **Золотая середина — Magnific на creativity 2**: невнятное пятно превращается в осмысленный объект, но лишнего не дорисовывается |
| 20:36 | **Правило выбора**: изображение уже хорошее → faithful; изображение мутное, геометрия поехала → creative, но креативность не задирать |
| 21:00 | Специализированные модели дают лучший результат и стоят дороже. От Krea того же добиться можно, но подобранная комбинация ползунков не переносится на следующее изображение |
| 21:40 | Подмодели: Magnific Precise — честный вариант, Topaz Generative и Bloom — креативные. Вывод: кто распыляется, делает хуже сфокусированных |
| 22:26 | Практика автора: чаще всего Krea (почти не ест токены, тонкая настройка, быстро), за качеством — в Magnific или Topaz |
| 22:50 | Отдельную подписку на Magnific или Topaz брать смысла нет, если не занимаешься апскейлом профессионально |
| 23:00 | Домашка: один кадр прогнать через Topaz, Magnific и Krea и сравнить три результата |
