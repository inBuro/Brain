# 2.9. Claude Design — визуальная страница на нашей ДС — 35:12

Отступление от продуктового рельса: лендинг живёт свободнее, чем продуктовые экраны, `final_screens` под это избыточен.

| Тайм-код | О чём |
| --- | --- |
| 0:00 | Куда идти: claude.ai → боковая панель → Design. Четыре режима: прототипирование, slide deck, from template, other |
| 1:54 | В Examples видно, что это не только лендинги: визуализация данных, интерактивные фрагменты кода, лоадеры — по очень коротким промптам |
| 3:00 | **Это не замена Figma.** Инструмент быстрого прототипирования и итеративной визуализации; плюс жёсткие лимиты |
| 4:00 | Создание своей ДС: Design Systems → Create. Первое поле — краткое описание компании и продукта: на палитру не влияет, но расширяет понимание, для чего собирается страница |
| 5:36 | Приём: описание продукта и описание облика ДС попросить у своего агента — он знает контекст среды |
| 6:20 | Источники ДС: ссылка на GitHub, локальная папка с компонентами — или, для дизайнеров, файл Figma |
| 7:27 | **Как выгрузить Figma**: логотип Figma → File → Save local copy → `.fig`, затем перетащить в Claude Design |
| 8:00 | **Ключевая тонкость**: по умолчанию подтягиваются все страницы файла (в примере 6 страниц, 154 фрейма). Оставлять только Foundation и Components. Sitemap, старые экраны и чёрно-белые wireframes создают ложный контекст — он примет их за эталон визуала |
| 8:50 | Он не переносит ДС, а анализирует и **воссоздаёт её на своём языке** — расхождения будут |
| 9:17 | Русский в системном промпте иногда ломает генерацию — автор перевёл поля на английский расширением DeepL |
| 10:40 | Генерация ДС занимает около 5 минут, вкладку не закрывать; внутри агентский процесс — SKILL.md, README, сборка UI-кита |
| 11:08 | **Лимиты**: claude.ai → Settings → Usage, у Claude Design отдельная строка. Выдаются раз в неделю. Автору хватило на две ДС и три лендинга — но как постоянный рабочий инструмент не годится |
| 13:03 | Выбор модели: самая свежая для фундаментальных вещей и первой итерации, попроще — для точечных правок текста и цветов |
| 13:30 | Design Files — папка проекта: шрифты, ассеты, UI-кит в виде HTML-элементов |
| 14:00 | **Фаза Needs Review**: агент выносит на проверку палитру, оттенки, семантические токены, размеры текста — по каждому Looks Good или комментарий |
| 15:00 | Живые расхождения: добавил лишний шрифт, которого в проекте нет; у карточки тег исчезал в статичном состоянии и оставался на hover — фиксится комментарием |
| 16:45 | Бонусом собрал интерактивную вариацию дашборда — поиск даже работает |
| 17:30 | Дальше: новый проект Landing Page на этой ДС. ТЗ запрашивается у своего агента из контекста среды и передаётся файлом `landing_spec.md` |
| 18:38 | **Важное ожидание**: Claude Design креативный и заметно отходит от ТЗ ради визуала. На 100% соответствия рассчитывать не стоит — доводить потом в своей среде |
| 19:20 | Сборка лендинга занимает 10–15 минут. Результат: hero, четыре отличия, четыре шага, блок прозрачности оплаты (пришёл из исследования болей), тарифы, статус серверов, FAQ, CTA — всё в своей ДС |
| 22:21 | **Tweaks** — альтернативные визуализации блока; кнопка Ideas сама находит узкие места. Пример: этапность «от регистрации до сервера» переделана в анимированный таймлайн |
| 26:06 | Осторожно с твиками: терминальный визуал в hero выглядел эффектно, но противоречил исследованию (пользователи просили Telegram) |
| 24:14 | Панель быстрых правок против чата: базовые правки текста, цвета, отступов доступны в панели, но записываются в код отдельной обработкой и тоже тратят лимиты |
| 27:56 | **Перенос в Figma, путь 1 (рекомендуемый)**: Share → export as standalone HTML (или передача в Claude Code) → попросить агента пересобрать лендинг в отдельной секции на своих компонентах, стилях и токенах. Медленнее, но аккуратно |
| 29:46 | **Путь 2 (быстрый)**: export as standalone HTML → плагин Figma `html.to.design`. При импорте **не включать** создание стилей и переменных — иначе разрушит вашу ДС |
| 31:49 | Минус пути 2: ничего не привязано к компонентам и переменным, вложенность наследует логику HTML. Годится для лендинга под вёрстку, не для продукта |
| 33:39 | Домашка: собрать лендинг своего продукта или фичи, прислать ссылку на Figma-фрейм; способ импорта — на выбор |
