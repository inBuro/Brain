# 2.8. Сборка финальных экранов — 10:55

Директива `final_screens` соединяет wireframes и UI-кит. Не просто заменяет прямоугольники на instance,
а доращивает wireframe до production и на лету выносит повторяющиеся блоки в UI-кит.

| Тайм-код | О чём |
| --- | --- |
| 0:00 | Почему «просто положить инстансы» мало: получится сырой экран — без иконок, с серыми квадратами и сущностями, описанными текстом через точки |
| 1:00 | Что не так с исходником: edge cases отсутствуют, пустые состояния не проработаны, в wireframe заложена сухая логика |
| 1:42 | **Фаза Pre-flight**: агент спрашивает про иконки (по умолчанию библиотека Lucide как самая нейтральная) и заново сканирует, что уже есть в библиотеке |
| 2:10 | **Фаза анализа достаточности wireframe** — специально добавлена автором: домашки делаются быстро, wireframe обычно неполон, и агент проектирует логику экрана, опираясь на эту оценку |
| 2:40 | **Фаза выноса повторяющихся блоков**: новые сущности сверяются с компонентной базой, повторы предлагаются к добавлению в UI-кит с апрувом |
| 3:28 | Брифинг можно отключить: «делай на своё усмотрение» — шаги согласования пропускаются |
| 3:40 | Перед отрисовкой агент проверяет, что всё записано в ДС внутри среды |
| 3:50 | **Эвристика предсказуемости**: спроси себя, во скольких приложениях есть такой экран. Настройки и профиль — соберёт спокойно, специфика сложнее. В целом закрывает ~90% |
| 4:30 | Где сбоит: режимы наложения, векторные фигуры с вычитанием, абсолютно позиционированные элементы — и потом это же плохо переносится в прототипирование |
| 5:00 | **Руками в любом случае**: логотип бренда, реальные изображения и фото, прототипы со связями внутри Figma |
| 5:12 | Демо: агент нашёл wireframes из урока 4 сам — среда сохранила контекст через несколько уроков |
| 6:00 | **Сравнение до/после.** Без четырёх дополнительных фаз получается аккуратно, но сухо: параметры сервера через точки, ни иконок, ни теней, ни цвета |
| 6:57 | После доработки: графики, тени, иконки, цветные акценты, структурированная мета вместо текста через точки |
| 7:30 | Разбор дашборда: карточки серверов с иконками и тегами, виджеты баланса и срока оплаты, список последних операций с цветовой индикацией зачисления и списания, всё на семантических переменных |
| 8:00 | Типовые ручные правки те же: выровнять по вертикали, поставить fill там, где блоки делят пространство |
| 8:45 | **Когда через MCP**: работы много и агент быстрее. **Когда руками**: точечная высота или оттенок — 5 секунд |
| 9:30 | Не через агента: прототипирование внутри Figma, отрисовка иконок (SVG вставит, но полагаться не стоит), эффекты, режимы наложения, вставка изображений |
| 10:26 | Домашка: 1–2 экрана — прогон жрёт прилично токенов. **Приём автора**: заранее создать страницу Screens и передать ссылку на неё вместе с директивой |
