# 3.9. Видео-генерация: пайплайн и консистентные кадры — 26:11

Пайплайн один и тот же: концепт → ключевые кадры → image-to-video → склейка (+ звук опционально).
Модели меняются каждый месяц, поэтому запоминаем не имена, а критерии.

| Тайм-код | О чём |
| --- | --- |
| 0:40 | **Критерий 1 — управляющий вход**: только текст, стартовый кадр, старт и финал, или video-to-video |
| 1:00 | **Критерий 2 — длительность и стыковка**: максимальная длина клипа, продление, бесшовная петля |
| 1:53 | Про петлю: можно подать один и тот же кадр как первый и последний, но цветокор всё равно поедет — лучше нативный loop |
| 2:00 | **Критерий 3 — аудио**: нативная генерация звука, липсинк (для UGC, в наших задачах вряд ли) |
| 2:20 | **Критерий 4 — motion fidelity**: как работает физика, не залипает ли движение на первом и последнем кадре |
| 2:40 | Срез рынка: **Veo** — универсал с native audio и высоким разрешением; **Kling** — сложное движение, несколько шотов, **поддерживает Start и End Frame**; **Runway** — всеядный i2v и управление камерой, но только Start Frame |
| 4:00 | Почему Start-only ограничивает: клипы по 3–6 секунд, для сценария их надо склеивать, а без End Frame стык не задать |
| 4:30 | **Seedance** — приличное аудио вместе с видео. **Gemini Omni** — быстро и эффектно, но сильно креативит и плохо управляется |
| 5:20 | Hailuo, Wan, LTX — не лидеры, пробовать, если не выходит на основных |
| 5:40 | **Дорога 1 — красивый ролик**: один эффектный клип из топовой модели, хватает для разовых задач |
| 6:00 | **Дорога 2 — полноценное видео**: связанная сцена, консистентность кадров, аккуратная стыковка. Держится связкой Сетка 4K + модель со Start и End Frame |
| 6:20 | **Почему нужна сетка**: даже один JSON-промпт в одном чате даёт разный фон, освещение и цветокор от генерации к генерации — рядом в Figma это сразу видно |
| 8:00 | Суть метода: три кадра генерируются **на одном холсте разом**, поэтому выходят в едином стиле, свете и текстуре |
| 9:21 | Модель для сетки — **Nano Banana 2**: следует указаниям, но оставляет долю креатива |
| 9:40 | Как готовить холст: выбрать соотношение (в демо 9:16), уложить в него нужное число кадров 16:9 **с минимальным запасом** — так выше качество каждого кадра, и пронумеровать ячейки |
| 11:12 | **4K в Figma не вставляется напрямую** — ресайзится. Нужен плагин **Insert Big Image** |
| 11:40 | Нарезка: инструмент Slice на 1600×900 по каждому кадру → экспорт Screen 1, 2, 3 |
| 13:04 | Директива `video_storyboard` рассчитана на оба пути и сама спрашивает: есть идея ролика или придумать |
| 13:30 | По умолчанию в директиве три кадра; нужно больше — сказать заранее |
| 14:58 | Что отдаёт директива: JSON на каждый фрейм, **отдельный grid-промпт** под метод сетки, два перехода (клип A и клип B) и whole-video prompt для быстрого пути |
| 15:40 | **Экономия**: не генерировать сетку сразу в 4K — сначала 1K, выбрать удачную раскадровку, потом апскейл |
| 16:48 | Апскейл сетки: через Nano Banana проще, через Magnific четче, но креативная модель портит текст |
| 17:20 | **Выбор видеомодели в Krea — Kling O3**: есть первый и последний кадр, 250 токенов, нормальный результат. Kling 3.0 вдвое дороже и заметно лучше |
| 17:50 | Как собирать: первый и второй кадр + описание перехода из директивы; затем второй становится первым для клипа B |
| 18:38 | Результат — плавный и **предсказуемый** переход |
| 19:20 | Add Audio внутри Krea бесполезен: подставляет посторонние голоса. Extend не даёт задать финальный кадр |
| 19:50 | Склейка: iMovie на Mac или бесплатный CapCut. Подрезать стыки ради динамики можно, но шов станет заметен |
| 20:30 | **Быстрый путь**: whole-video prompt + три кадра в Gemini Omni |
| 21:00 | Что получается: звук, реалистичная фактура, но уезжают освещение и материалы, появляется посторонний фон, меняется сюжет |
| 22:22 | Вывод по Omni: делает сам, быстро и красиво — но контролировать сложно |
| 23:00 | Звук отдельно: библиотека CapCut (часть треков только на премиуме) либо модель с нативным аудио |
| 24:16 | Итог: точный путь — раскадровка, поэтапная генерация, склейка; быстрый — Gemini Omni, когда консистентность не критична |
| 24:50 | Домашка: одно видео для своего продукта, выложить по открытой ссылке — проверить настройки приватности |
| 25:20 | Если Gemini не пускает: он открывается под аккаунтом Google по умолчанию — добавить профиль с купленным аккаунтом и заходить из него |
