Технический урок.
Разбираемся, что такое Model Context Protocol и зачем он между Claude Code и Figma. Смотрим, что умеет Figma MCP: чтение структуры файла, запись на канвас, работу с FigJam и Code Connect. Понимаем, почему в модуле берём remote-сервер — только он даёт write-функционал через use_figma. Дальше — по шагам подключаем MCP через готовую директиву: правка ~/.claude.json, перезапуск IDE-расширения, OAuth в браузере. На первом read-вызове агент читает твой Figma-файл и показывает его структуру. В конце урока разбираем лимиты (200 запросов в день на Pro), правило батчинга промптов и Framelink как бесплатный fallback.

После урока ты сможешь:

    Подключать Figma MCP к Claude Code через директиву.
    Делать первый read-запрос: «расскажи, что в этом фрейме».
    Понимать ограничения Pro-плана и правило батчинга, чтобы не упираться в лимит.
