# Директива: Раскадровка для видео-генерации (Сетка 4K + image-to-video)

## Задача
Собрать готовую раскадровку для короткого видео о продукте студента: три консистентных ключевых кадра через метод Сетки 4K и два перехода между ними для image-to-video со Start и End Frame.

## Контекст
Студент собирает короткое видео по пайплайну: три ключевых кадра в едином стиле → оживление в image-to-video → склейка в одно непрерывное видео. Кадры генерируются методом Сетки 4K на Nano Banana Pro — одно 4K-изображение, разбитое на пронумерованные ячейки, где каждая ячейка описана отдельно, чтобы весь сет вышел в одном стиле и освещении. Видео собирается из двух клипов: кадр 1 → кадр 2 и кадр 2 → кадр 3, где конец первого клипа становится началом второго.

## Инструкция

1. Прочитай контекст продукта студента из материалов прошлых модулей: бриф / PRD, бренд-направление, дизайн-систему (цвета, тон, объект). Нужно понять, что за продукт, какой у него визуальный язык и какой объект логично показать в hero-видео.

2. Определи сюжет видео:
   - Если студент задал идею — возьми её и оформи. Не переписывай замысел, оформляй то, что он хочет показать.
   - Если идеи нет — придумай простой уместный сюжет под этот продукт. Хорошие варианты: облёт продукта камерой, переход между состояниями экрана приложения, движение по сцене с продуктом. Сюжет — короткий и связный, без сложной хореографии.

3. Раскадруй сюжет на три ключевых кадра. Это должна быть прогрессия одного и того же объекта/сцены в едином стиле: например, три ракурса облёта (спереди → три четверти → сбоку) или три состояния (исходное → промежуточное → финальное). Кадр 1 — старт, кадр 3 — финал, кадр 2 — осмысленная середина между ними.

4. Опиши два перехода — что происходит в движении между кадрами:
   - Переход A: кадр 1 → кадр 2 — какое движение камеры или объекта связывает первый кадр со вторым.
   - Переход B: кадр 2 → кадр 3 — какое движение связывает второй кадр с третьим.
   Описание перехода — это то, что увидит зритель в клипе: куда едет камера, что меняется в объекте, характер движения (плавный, медленный).

## Формат результата

Сохрани готовую раскадровку в файл `video_storyboard.md`. Файл состоит из двух частей, обе готовы к копированию без редактирования.

### Часть 1 — Промпт для Сетки 4K (Nano Banana Pro)

Один промпт на генерацию изображения с сеткой из трёх пронумерованных кадров в 4K. Структура промпта:
- Указание сгенерировать одно изображение, разбитое на сетку из трёх кадров с номерами 1, 2, 3.
- Общий стиль, освещение, фон, материалы — единые для всех трёх ячеек (это и держит консистентность).
- Описание каждой ячейки отдельно: «в кадре 1 — …, в кадре 2 — …, в кадре 3 — …».
- Указание на разрешение 4K и продакшен-качество.
- Промпт — на английском (модели стабильнее слушаются англоязычный промпт), но с понятными студенту русскими подписями над ним.

### Часть 2 — Промпты для image-to-video (Start + End Frame)

Два коротких промпта, по одному на клип:
- **Клип A (Start = кадр 1, End = кадр 2):** описание движения в переходе.
- **Клип B (Start = кадр 2, End = кадр 3):** описание движения в переходе.
Каждый промпт описывает только движение и его характер — без повторного описания самого объекта, он уже задан кадрами. На английском, с русской подписью какой кадр Start, а какой End.

## Важно
- Все три кадра — один и тот же объект/сцена в едином стиле и свете. Если кадры разойдутся по стилю, клипы не сошьются.
- Кадр 2 должен быть честной серединой между 1 и 3, иначе переходы получатся рваными.
- В переходах описывай движение, а не статичную картинку — это вход для видео, а не для генерации изображения.
- Не выдумывай характеристики продукта, которых нет в материалах прошлых модулей. Опирайся на бренд и объект студента.
