Первая боевая задача модуля.
MCP подключён — теперь получаешь sitemap и user flow прямо на FigJam-канвасе, без промежуточных экспортов и перерисовок. Разбираешь, как устроена директива prd_to_sitemap: два этапа — сначала всё в текстовых файлах ia/ с апрувом после каждой фазы (инвентаризация экранов → sitemap → приоритеты → user flow), только потом отрисовка через MCP. Логика простая: MCP-лимит стоит денег и времени, а текстовое дерево переделать в пятнадцать раз быстрее, чем на канвасе. На канвас агент выходит одним-двумя вызовами generate_diagram — sitemap и flow рисуются с авто-раскладкой за секунды.

После урока ты сможешь:

    Запускать директиву prd_to_sitemap в Claude Code и проходить все текстовые фазы с апрувами.
    Отрисовывать sitemap и user flow на FigJam через generate_diagram одной командой.
    Ловить типичные ошибки агента: выдуманные экраны, глубокое дерево, каша на больших sitemap.
