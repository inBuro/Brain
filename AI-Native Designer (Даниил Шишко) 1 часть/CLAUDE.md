# AI-Native Designer

База знаний по курсу Даниила Шишко «AI-Native Designer», часть 1.
Источник — 44 видеоурока в четырёх модулях + директивы-промпты, которые в них разбираются.
Задача проекта: быстро отвечать на любой вопрос по содержанию курса, не пересматривая видео.

Язык проекта — русский: исходник целиком русскоязычный, транскрипты и индексы дословно с ним сверяются.

## Как отвечать на вопрос по курсу

1. Найти вопрос в [QUESTIONS.md](QUESTIONS.md) — каталог всех вопросов курса с адресом «урок @ тайм-код».
   Если вопроса там нет — [INDEX.md](INDEX.md), карта уроков и тем.
2. Открыть конспект урока `notes/<slug>.md` — тезисы с тайм-кодами. Обычно ответ уже там.
3. Нужна дословная формулировка — `grep -i` по `transcripts/*.txt`, затем
   `.pipeline/vtt-digest.py transcripts/<slug>.vtt` для чтения куска с тайм-кодами.
4. Ответ давать со ссылкой: урок (номер + название) и тайм-код.
5. Если вопрос про «как запустить X» — смотреть саму директиву (`directive_*.md` в папке урока),
   она первичнее пересказа в видео. Сводка всех директив — [DIRECTIVES.md](DIRECTIVES.md).

## Что где лежит

| Что | Где |
| --- | --- |
| Видео | `<модуль>/<урок>/*.mp4` |
| Аннотация урока (что будет, полезные ссылки) | `<модуль>/<урок>/*.txt` |
| Директивы-промпты | `<модуль>/<урок>/directive_*.md` |
| Транскрипты (текст) | `transcripts/<slug>.txt` |
| Транскрипты с тайм-кодами | `transcripts/<slug>.vtt` |
| Конспекты уроков с тайм-кодами | `notes/<slug>.md` |
| Каталог директив | [DIRECTIVES.md](DIRECTIVES.md) |
| Карта уроков и тем | [INDEX.md](INDEX.md) |
| Каталог вопросов курса | [QUESTIONS.md](QUESTIONS.md) |
| Пайплайн транскрибации | `.pipeline/` |
| Промежуточные файлы (логи, wav, черновые выгрузки) | `.tmp/`, вне git |

Новый вопрос, ответ на который нашёлся в транскриптах, — дописывать в `QUESTIONS.md`,
чтобы каталог оставался полным.

Slug урока — стабильный ключ: `00-*` вводный, `m1-*` AI Strategist, `m2-*` System Architect,
`m3-*` Visual Engineer, `m4-*` AI Prototyper & Agents.

Адресация в ответах — `модуль.урок @ тайм-код`, нумерация модулей курса совпадает
с номером папки на диске (папку `0.` занимает вводный урок): `1.5` — это урок
`1. AI Strategist/1.5. AI-аудит существующего продукта`. Полная таблица — в шапке `QUESTIONS.md`.
Соответствие slug ↔ видео — в `.pipeline/manifest.tsv`.

## Архитектура

Трёхслойная, как в уроке 1 курса (@ 25:26), с поправкой на эту среду.

| Слой | В курсе | Здесь |
| --- | --- | --- |
| Правила и архитектура | `GEMINI.md` | этот `CLAUDE.md` |
| Директивы — SOP под задачу | `directives/` | `~/Brain/directives/` и скиллы `.claude/skills/`, общие на всю среду |
| Исполнение — детерминированные скрипты | `execution/` | `.pipeline/` |
| Промежуточные файлы | `.tmp/` | `.tmp/`, удаляется и пересобирается в любой момент |
| Ключи | `.env` | `~/.config/<сервис>/env` (600), в проекте не хранятся |

Правила, которые из этого следуют:

- **Артефакты не в корне.** Транскрипты — в `transcripts/`, конспекты — в `notes/`.
  В корне только четыре сводных документа: `CLAUDE.md`, `INDEX.md`, `QUESTIONS.md`, `DIRECTIVES.md`.
  Новый вид артефакта — заводить папку, а не сыпать файлы рядом с индексами.
- **Промежуточное — в `.tmp/`.** Логи прогонов, извлечённые wav, черновые выгрузки.
  Всё оттуда должно пересобираться скриптом, поэтому в git не попадает.
- **Сначала искать готовый инструмент в `.pipeline/`,** потом писать новый.
  Новый скрипт — туда же плюс строка в таблицу «Что где лежит».
- **Self-annealing.** Скрипт сломался — починить и дописать причину сюда,
  чтобы следующий прогон не наступил на те же грабли (так появились правила про `-nostdin` и `--prompt` ниже).

## Пайплайн транскрибации

Локально, whisper.cpp + модель `large-v3-turbo` (`~/.cache/whisper/`), язык `ru`.
Перезапуск (пропускает уже готовое): `.pipeline/transcribe.sh`.
Аудио извлекается во временную папку сессии, в репозиторий не кладётся —
если wav'ов нет, скрипт извлечёт их сам.

Правило: `ffmpeg` и `whisper-cli` в циклах вызывать с `-nostdin` / `</dev/null` —
иначе они съедают stdin цикла и имена файлов разъезжаются.
Второе правило: без `--prompt` с пунктуацией модель отдаёт сплошной текст без точек и заглавных,
поэтому в скрипте задан затравочный `PROMPT`.

Читать транскрипт удобнее через `.pipeline/vtt-digest.py transcripts/<slug>.vtt [сек]` —
он схлопывает `.vtt` в блоки вида `[M:SS] текст`.

Хвостовые галлюцинации на тишине («Продолжение следует…», «Редактор субтитров…») вычищены
скриптом `.pipeline/strip-artifacts.py` — прогонять его после каждой новой транскрибации.
