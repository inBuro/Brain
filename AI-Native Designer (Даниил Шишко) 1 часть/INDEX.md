# Карта курса

44 урока, ~10 ч 18 мин. Четыре содержательных модуля плюс вводный урок.
Колонка «slug» — ключ урока: конспект `notes/<slug>.md`, транскрипт `transcripts/<slug>.txt`
и `transcripts/<slug>.vtt` с тайм-кодами.

**Нумерация модулей взята из самого курса и на единицу меньше номера папки на диске** —
папку `1.` занимает вводный урок. Соответствие подписано у каждого модуля ниже.

## Вводный урок

Папка на диске: `1. Старт. Доступ, среда и инструменты`.

В этой ступени **один урок, и так задумано**: пошаговые инструкции по доступам автор держит
не в видео, а в Notion-гайде (0 @ 0:00), потому что они постоянно меняются. Видео объясняет только,
зачем нужна каждая вещь.

| № | Урок | Длит. | Slug | Материалы |
| --- | --- | --- | --- | --- |
| 0 | Старт. Доступ, среда и инструменты | 11:48 | `00-start-setup` | Notion-гайд по доступу, VS Code + Claude Code |

Про что: доступ из РФ/РБ (гео, оплата, номер, IP), почему обычный VPN не годится — нужен свой зарубежный сервер;
своя подписка против готового аккаунта; установка VS Code с расширением Claude Code.
Если ты не в РФ/РБ и есть зарубежная карта — из урока нужен только финальный раздел про установку.

Ключевые понятия модуля:
MCP как мост между Claude Code и Figma; remote-сервер ради write через `use_figma`; лимит 200 запросов в день на Pro, батчинг промптов, Framelink как бесплатный fallback;
общий приём директив — сначала текстовые фазы с апрувом, только потом канвас (переделать текст в 15 раз дешевле, чем канвас);
`generate_diagram` для sitemap и user flow на FigJam; low-fi wireframes с Auto Layout до дизайн-системы;
три сценария ДС — A ставим с нуля (`ds_baseline`), B берём из Figma Community, C индексируем корпоративную (`ds_scan`);
три слоя токенов: Primitive → Semantic → компонентные, через коллекции Figma Variables;
`ds/CONTRACT.md` — без контракта ДС остаётся декорацией; правило «нет компонента — сначала заводишь в ДС»;
пять фаз `grow_ui_kit` (read → brief → md → canvas → write+audit);
матрица variants × states × sizes и где AI плывёт (25+ ячеек, focus ring, loading);
composition map как мост между wireframe и финальным экраном;
эвристика «страница продаёт или работает» — Claude Design против `final_screens`, `.fig`-onboarding для своей стилистики;
`screens_audit` — read-only проверка по шести пунктам, матрица покрытия состояний.
