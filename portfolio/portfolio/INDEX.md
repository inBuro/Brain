## Convention

Dated files (`<topic>-YYYY-MM-DD.md`) are snapshots — never rewritten in
place; a new date means a new file placed alongside the old one (see project
`CLAUDE.md`). When a topic accumulates multiple dated snapshots, add its
reading order here instead of merging or deleting anything.
