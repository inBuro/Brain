## 0. Как читать эту страницу

Всё ниже получено **без доступа к проду и к коду сайта**. Ограничения окружения на момент аудита:

- `fadercraft.com`, `maxforlive.com` и preview-хост `*.pages.dev` — заблокированы egress-политикой окружения.
- Репозиторий лендинга недоступен: `list_repos` отдаёт только `inBuro/Brain` и `inBuro/Chess-Demo`.
- В той сессии Google Search Console не читался — **но это ограничение конкретной сессии, не факт отсутствия доступа.** На машине уже есть рабочий локальный доступ к GSC API (`~/.config/google/gsc-service-account.json`, service account с правами Owner на `sc-domain:fadercraft.com`, хелпер `~/.config/google/gsc.sh`) и автономный launchd-монитор (`com.fadercraft.gsc-index-monitor`, раз в 2 дня пересабмичивает sitemap и проверяет 7 ключевых URL — отчёт лежит в `~/.config/google/gsc-reports/latest.md`). Читается это только при выключенной песочнице (ключ под `~/.config`), поэтому сессии с ограниченным доступом к файловой системе его не видят. Проверено 2026-08-16 постфактум — часть находок в §4 этой правки уже закрыта данными монитора.
- В подключённом почтовом ящике **нет ни одного письма Gumroad** — аккаунт продавца заведён на другую почту, данные о продажах недоступны.

Поэтому у каждого факта ниже проставлен статус: **✅ подтверждено** (виден в индексе Google), **❌ опровергнуто** (вики расходится с наблюдаемой реальностью), **❓ не проверяемо** (нужен доступ).

⚠️ Отдельная оговорка про метод: поисковая выдача **не является полным дампом индекса**. Отсутствие страницы в результатах — повод проверить, а не доказательство деиндексации.

## 1. Исходный вопрос основателя

> «Имеет ли смысл перевести страницы с гайдами на французский, uk English, немецкий, для лучшего индекса в этих странах?»

**Вердикт: нет, не сейчас. Вариант en-GB не имеет смысла и в перспективе.**

Аргументы:

1. **Аудитория ищет по-английски.** SEO-таргеты проекта (`docs/superpowers/specs/2026-05-01-fadercraft-launch-design.md:154`) — `launch control xl mk3 max for live`, `lcxl mk3 ableton mapping`. У этих терминов нет немецких/французских эквивалентов: «custom mode», «Max for Live», «sends», «encoder bank» немцы и французы гуглят как есть. Локализованная страница целится в запросы с околонулевой частотностью, а на английский запрос из Германии английская страница ранжируется и так.
2. **en-GB — это орфография, а не язык.** Бонуса в британской выдаче за неё нет; получается дубль контента, hreflang-развилка и canonical-риск при нулевом апсайде. Для UK работают ссылки и упоминания, не перевод.
3. **База не готова.** В индексе шесть из семи ключевых страниц, одна только что регрессировала в noindex (см. §3), содержимое `sitemap.xml` не сверено, плюс дубль всего сайта на preview-хосте. Локализация в такой конфигурации умножает проблему, а не решает её.
4. **Стоимость не разовая.** Копи живая (терминология менялась: `signals → sources`, `gumroad-description-sends-follower.md:113`). Каждая правка формулировки превращается в 4 правки на языках, которые никто не проверит. Протухший перевод хуже отсутствия перевода.
5. **LLM-поиск.** По нишевым техническим темам ассистенты цитируют преимущественно англоязычные источники.

**Условия для пересмотра** (проверяются по GSC, см. задачу D1):

- английский органик даёт стабильный поток (ориентир ≥1000 сессий/мес);
- в отчёте «Страны» по DE/FR видны **показы с нормальной позицией, но низким CTR** — только это доказывает языковой барьер, а не отсутствие видимости;
- есть страница-победитель, которую есть смысл клонировать (переводят выигравший контент, а не всё подряд).

Тогда переводить не сайт целиком, а одну-две страницы, руками, с hreflang. Список языков пересобрать по данным: по объёму Ableton-аудитории DE обычно интереснее FR, а ES/PT-BR/JP нередко крупнее обоих.

Отдельная история — **перевод Quickstart для покупателей**. Это не SEO, а качество продукта; окупается, когда появится заметная доля покупателей из конкретной страны.

## 4. ❓ Не проверяемо без доступа

Ранее в этом списке были «отправлен ли sitemap» и «судьба `/free-custom-modes`» — оба сняты выше данными локального GSC-монитора, вопрос закрыт без доступа к репозиторию лендинга. Осталось непроверяемым без доступа к коду/проду:

1. **Содержимое `sitemap.xml`** — сам факт отправки подтверждён (см. §3), но актуален ли список `<loc>` (не тянет ли старые URL до реструктуризации) — неизвестно.
2. **`robots.txt`, canonical, `_headers`, `_redirects`** — в том числе есть ли защита preview-хостов от индексации и живы ли vanity-редиректы.
3. **Роуты `/sf`, `/update`, `/sends-follower/updates`** — существуют ли.
4. **Раскатан ли Control XL v1.1** (`version.json` → `latest`, «Last Updated» в листинге maxforlive 15522).
5. **Продажи и страны покупателей** — нечем проверить, есть ли вообще покупатели из DE/FR. Это ровно те данные, которые нужны для решения по локализации.
6. **KVR-листинг** (`roadmap.md:395`) — следов не нашёл, похоже не сделан. Доказательство слабое.

## 5. Очередь задач для агента

Порядок блоков — это порядок исполнения. Блок A гейтит B и C.

### A. Доступы (гейт, исполнитель — человек)

- [ ] **A1. Выдать один из двух доступов к коду/проду.** Без любого из них блоки B/C неисполнимы:
  1. установить GitHub App на репозиторий лендинга (`fadercraft-landing`) → проверка по коду;
  2. разрешить `fadercraft.com` и `maxforlive.com` в network policy окружения ([документация](https://code.claude.com/docs/en/claude-code-on-the-web)) → проверка живого прода.
  **Готово, когда:** агент может прочитать `robots.txt`/`_headers`/canonical любым из способов.
  ⚠️ **GSC-доступ сюда не входит — он уже есть локально и не требует новой выдачи.** `~/.config/google/gsc-service-account.json` + `~/.config/google/gsc.sh` (нужен выключенный sandbox), плюс готовый отчёт `~/.config/google/gsc-reports/latest.md`, обновляется раз в 2 дня автономно. См. §0 и §3 — часть выводов этого брифа уже получена оттуда постфактум.

### B. Сверка фактов (после A)

- [ ] **B1. Инвентаризация `sitemap.xml`.** Сам факт отправки уже подтверждён (§3) — сверить список `<loc>` с фактическими роутами на устаревшие/недостающие URL.
  **Готово, когда:** в этой странице появился список URL из sitemap и вердикт «актуален / устарел».
- [ ] **B2. Расследовать регрессию `/guide/…mk3-across-live-sets`** в `Excluded by 'noindex' tag` (см. §3) — та же причина, что у предыдущего эпизода в июле (`X-Robots-Tag` из preview-деплоя, утёкший в краул)? Если да — это тот же баг, что и C1, чинится одним фиксом.
  **Готово, когда:** причина регрессии названа и явно связана (или явно не связана) с C1.
- [ ] **B3. Аудит индексируемости по всем роутам** — `robots.txt`, `<link rel=canonical>`, `meta robots`, заголовки. Проверить, что canonical указывает на апекс, а не на pages.dev.
- [ ] **B4. Проверить роуты `/sf`, `/update`, `/sends-follower/updates`** и синхронность `_redirects` с [[outbound-links]].
- [ ] **B5. Статус Control XL v1.1** — `api/version.json` `latest`, версия и «Last Updated» в листинге maxforlive 15522, упоминание v1.1 в описании Gumroad.

### C. Фиксы

- [ ] **C1. Закрыть preview-хосты от индексации** (главный подтверждённый дефект, вероятно общий источник и для B2). Отдавать `X-Robots-Tag: noindex` либо `Disallow: /` для любого хоста кроме `fadercraft.com` (в Cloudflare Pages — через middleware/Function или `_headers`; `_redirects` для этого не годится), затем убрать уже проиндексированный URL через **GSC → Удаления**.
  **Готово, когда:** preview-URL отдаёт noindex, заявка на удаление подана, брендовый запрос и `/guide/…mk3-across-live-sets` перепроверены через неделю по монитору.
- [ ] **C2. Обновить `sitemap.xml`**, если B1 нашёл расхождения — доотправка не нужна (это уже автоматизировано, см. A1), нужен только актуальный список URL внутри файла.
  **Готово, когда:** список `<loc>` в sitemap совпадает со списком реальных роутов.
- [ ] **C3. Проверить, что три продуктовые страницы связаны внутренними ссылками** с хаба и футера — страница без входящих ссылок остаётся сиротой даже после индексации.

### D. Данные под решение о локализации

- [ ] **D1. Выгрузить GSC → Эффективность за 3 месяца**, вкладки «Страны» и «Запросы», CSV положить в `_Inbox/`.
  **Готово, когда:** по DE/FR/GB известны показы, CTR и средняя позиция.
- [ ] **D2. Свести страны покупателей** из Gumroad (нужен доступ к ящику продавца или CSV-экспорт).
- [ ] **D3. Вынести вердикт по локализации** по критериям из §1 и записать в эту страницу. **До закрытия D1 переводы не начинать.**

### E. Гигиена вики

- [ ] **E2. Завести синтез-страницу продукта Dynamic Focus** в вики и добавить в `index.md` — материал уже есть (roadmap Phase 3, `log.md`, `outbound-links.md`), не хватает только собранной страницы уровня [[Sends Follower]]. Не факт-гэп, а гэп синтеза.
- [ ] **E3. Разобраться с расхождением GSC-property** (10 июня против 24 июля) — назвать, какая property рабочая.
- [ ] **E4. Записать итоги в `wiki/log.md`** по формату журнала.
