# workflows

Воркфлоу — тонкая обёртка над директивой: вызывается одной командой, жёстко привязывает запуск к конкретному файлу директивы и спрашивает недостающий вход до старта. Смысл ровно тот, что в курсе (урок 1 @ 21:26): когда директив много, агент не всегда угадывает, к какой обратиться, — воркфлоу снимает угадывание.

**Разделение труда.** Процедура целиком живёт в `../directives/`. Здесь — только привязка: какую директиву прочитать, что спросить, какие входы проверить. Правишь процедуру — правишь директиву, не воркфлоу.

## Как запускать

В Claude Code — слэш-командой по имени файла: `/brief`, `/prd`, `/ds-scan`. Файлы связаны симлинками из `.claude/commands/`, так что правка здесь сразу видна команде. Аргумент передаётся следом: `/brief мобильный банк для самозанятых`.

В Antigravity — тот же текст: Customization → Workflows, поле Description и тело; вызов через `/` из чата.

Зачем нужен каждый и в какой момент за ним тянуться — [_catalog.md](_catalog.md).
