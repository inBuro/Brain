description: Развернуть новый проект в ~/Brain: структура папок + свой CLAUDE.md по шаблону
argument-hint: [название проекта]
---

Разверни новый проект в `~/Brain` по шаблону `~/Brain/templates/project-claude-md.md`.

1. Прочитай шаблон целиком и корневой `~/Brain/CLAUDE.md` — новый проект должен лечь в уже принятую раскладку, а не вводить свою.
2. **Спроси до старта:** как называется проект, о чём он и какие артефакты будет производить. Если название передано в `$ARGUMENTS` — бери оттуда, остальное всё равно уточни.
3. Имя папки — lowercase, без пробелов. Уже существующие папки не переименовывать.
4. Создай: папку проекта, `raw/` (если будут внешние источники), `.tmp/`, папки под артефакты по ответам из шага 2, и `scripts/` только если детерминированные скрипты действительно предвидятся — пустых папок не плодить.
5. Заполни `CLAUDE.md` проекта из шаблона: убери угловые скобки-плейсхолдеры, оставь только то, что для этого проекта правда. Пустых разделов «на будущее» быть не должно.
6. Добавь строку про проект в `~/Brain/CLAUDE.md`, раздел «Проекты».
7. Проверь, что `.tmp/` попадает под `**/.tmp/` в корневом `.gitignore`, и покажи получившееся дерево.

Ключи в проекте не создавать: они живут в `~/.config/<сервис>/env`.
