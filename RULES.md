# Правила

Железные правила работы, общие для всех проектов. Не проектная документация — то, что
нарушать нельзя независимо от задачи.

## Ассеты

**SVG забирается вместе с `viewBox` — как экспортирован. Никогда не подрезать.**

Отступы внутри кадра — это решение дизайнера, а не пустое место. Если обрезать `viewBox`
по границам графики, картинка растягивается на весь бокс, куда её поставили, и правки
размера внутри фрейма в Figma перестают на что-либо влиять — они молча отменяются кропом.

Размер задаётся там, где ему место: в коде (`icon.size`, ширина в CSS и т.п.). Если иконка
выглядит мелкой или крупной — менять число в коде или спросить, но не переобрамлять графику.

## Figma

**Всегда читать структуру файла через REST API, не через MCP-мост к Figma desktop.**

`get_metadata` без `nodeId` (десктоп-мост) отдаёт только страницы, уже подгруженные в
текущей сессии приложения — не весь файл. На файле с 138 страницами он показал 3 и
создал ложную уверенность, что остальные не существуют. REST API
(`curl -H "X-Figma-Token: $FIGMA_TOKEN" "https://api.figma.com/v1/files/:fileKey?depth=1"`,
токен в `~/.config/figma/env`) отдаёт полное дерево независимо от того, что открыто в
приложении. Мост можно использовать для скриншотов и design-context по уже известному
nodeId — но для «сколько страниц в файле» и «есть ли там X» источник истины только REST.

## Git и деплой

**Коммит и деплой — только по явной просьбе.** Не делать автоматически после каждой правки.

`wrangler pages deploy` (и аналоги) публикует то, что лежит на диске, – коммит для этого
не нужен. Ни коммит, ни деплой не следуют автоматически из «внеси правку» или «поправь
текст». Явные сигналы деплоить – «задеплой», «выложи», «покажи на проде» и т.п. Без них
изменения остаются локально; собранное на диске всегда можно посмотреть на localhost.

## Тире

**Короткое (дефис, `-`) и среднее (en dash, `–`) – да. Длинное (em dash, `—`) – никогда.**

Применяется везде: копирайт, документация, код-комментарии, эта заметка. `scripts/typograph.py`
в портфолио-репо (и любой аналогичный typography-скрипт в других проектах) конвертировал
одиночный дефис между пробелами в em dash – это баг конвейера, не желаемое поведение,
чинить на месте, где найдётся. Уже сгенерированный текст с `—` – заменить на `–` при
следующей правке этого блока, отдельным проходом не гнаться.
