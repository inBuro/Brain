# Ось UX-фреймворки

18 канонических фреймворков, по одному `.md` на каждый, в `rules/awesome-ux-skills/`. Читать 1–3 файла под задачу через Read, не пересказывать по памяти — применять Output Format файла буквально.

**Провенанс:** github.com/tommyjepsen/awesome-ux-skills (Tommy Jepsen), установлено 2026-06-24. Вендорский пак — внутренности не переписываются, обновление = перекопировать `.md` в `rules/awesome-ux-skills/`.

## Порядок работы

1. Определи вопрос (исследование / аудит UI / AI-фича / приоритизация) → 1–3 фреймворка по карте выше.
2. Прочитай файл(ы) через Read, применяй структуру и Output Format буквально.
3. Не тащи нерелевантные рамки — лишний фреймворк = шум. Если ни один не подходит — отвечай общими принципами, не натягивая рамку.

## Правила

Первоисточники нетронутыми в `rules/awesome-ux-skills/`. Ось ими дирижирует через карту тем выше.
