# UX-research — роутер группы

| Задача | Подскилл |
|---|---|
| Любой вопрос про метод исследования, аудит (эвристики/accessibility/cognitive load/persuasion), персоны/journey/empathy, приоритизацию, проектирование AI-фичи | subskills/frameworks — карта тем внутри выбирает конкретный фреймворк |

## Дедуп-вахта

- **ux-research vs design**: разные слои одной пары. `ux-research` — стратегия/критика/методология (что строить, что не так, в какой рамке думать). `design` — исполнение/craft (Figma, код, токены, полировка). Персона `ux-researcher` работает по обеим группам: этой — за рамками мышления, `design` (better-interface/interface-review/design-anti-slop/mobbin) — за конкретными UI-проверками. Не сливать: у `ux-research` нет `use_figma`/кода, только чтение и вывод текстом.
