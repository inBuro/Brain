Source: Eagle app library `~/Pictures/My data and visual technicks base.library` — a personal swipe file of landing pages / UI screenshots he's been collecting since 2023, tagged by pattern (footer, hero, layout, colors, saas, fintech...). Mostly Awwwards/Godly-style showcase sites across many small studios, no single dominant source. 311 active items, 89 tags. Full raw index (name+url+tags per item) → [[taste-tag-index]] (`tag-index.md`) — pull that when a task needs concrete reference links for a specific pattern (e.g. "footer" or "pricing").

He keeps adding to this library, so it's a live artifact, not a fixed archive — `tag-index.md` is regenerated by `regen-tag-index.py` in this folder rather than hand-maintained. Run `python3 regen-tag-index.py --check` (exit 1 = stale) before leaning on the index for something that matters, and `python3 regen-tag-index.py` to refresh it — cheap, no need to ask first.

This is **taste, not a design system** — it's what he bookmarks as good, not what any current product ships. Use it to calibrate direction on new/greenfield work (Large-scale tasks per the agent's scale triage), never to override an existing product's DS or hard rules. Where it validates something already in a DS (see below), that's a strong signal; where it conflicts, the product DS wins.

## Taste read (grounded in visual sampling of 25 items across top tags, 2026-08-14)

**Hero = one oversized headline, almost no supporting cast.** Nearly every saved hero is dominated by a single huge line (or two-three short lines) of type — often type so large it nearly fills the viewport (VUCKO's wordmark, GenCell's "POWER FOR HUMANITY" over a drone shot, LiveChat's "Chat. Sell. Support."). Body copy is short, one CTA, rarely a second competing action. This is the single strongest, most consistent signal in the collection.

**High-contrast two-mode palette, not middle-of-the-road corporate.** Two recurring modes, both saved a lot, almost nothing in between:
- **Dark + one glowing accent** — near-black bg, one saturated color doing all the work (Reflect Notes' purple radial glow, CodeSandbox's neon-yellow-on-black, Non-Linear Studio's white-on-black with one blue accent object, Specify's dark-purple gradient text).
- **Warm off-white/cream + one saturated accent** — never plain white, always a warm cream or beige base, dark text, one accent color carrying CTAs (Duck English cream+lime, Rockmuse warm brown/cream, Faizur white+orange, Alphavite cream+orange).
Plain corporate blue-on-white SaaS is essentially absent from what he keeps.

**Typographic personality via mixing weights/styles, not via color.** A recurring move: bold grotesk headline with one word swapped to italic serif for editorial contrast (Rockmuse: "A design *partner* in a new way"; Duck English: serif italic "The School You Deserve"). Reads as a designed accent, not a random flourish — worth reaching for when a headline needs one word to carry emotional weight.

**Pill / fully-rounded buttons, consistently.** Across fintech, SaaS, and playful brands alike — CodeSandbox, Duck English, Kaleido, Faizur, Rockmuse all use full pill-radius CTAs. Sharp-cornered or barely-rounded buttons are rare in the set.

**Fintech/crypto references lean saturated brand-color blocks + tilted/floating card mockups**, not sober enterprise gray (Kaleido's indigo, Finom's lavender, StealthEX's dark+yellow, Polygon's near-black+violet diamonds). Cards/UI screenshots shown at a slight tilt or in an isometric stack rather than flat-on. Relevant for bifi/DeFi work specifically.

**Architectural/aerial photography as full-bleed hero backgrounds** where the product has a physical or "real-world impact" story (GenCell's drone shot, Cargokite, Crest real-estate render) — moody, natural light, not stock-corporate.

**Friendly SMB/onboarding illustration uses hand-drawn-feeling connector lines and sticker collage** (Alphavite's dotted funnel diagram, Givingli's floating stickers) — a playful register kept distinct from the SaaS/fintech register above, pulled out only for consumer/SMB-facing products.

**Client-logo trust bars are common** on SaaS/fintech (Kaleido, LiveChat, Rockmuse) — greyscale logo row directly under the hero fold.

## Reading the library's own structure as signal

How Kirill tags an item is itself information — not just what's in the screenshot. Tag-count distribution across the 311 items: 4 untagged, 40 single-tag, then a bell curve peaking at 2-4 tags, tapering to a handful of 8-14-tag items.

- **Single-tag items (40) are precise callouts** — he saved it for exactly one thing, not "a good site overall." Examples: two Awwwards "grids" saves are both product-detail spec/collection grids from the same studio (Giopato Coombes) — a specific grid-of-specs pattern, not a general site bookmark; a "portfolio" single-tag save (Flayks, Atly) is about the portfolio-site genre itself, not a component; "parallax" on an NFT game site isolates just that one scroll effect out of an otherwise-irrelevant site. When a task matches a single-tag item's one tag, that item is a sharper reference than a same-tagged item buried in an 8-tag entry.
- **`real good` (81 items) is a starred/superlative flag, not a category** — it co-occurs most with `layout`, `footer`, `features`, `colors`, `menu`, `hero` in that order. When he stars something "real good," it's almost always for how the overall page is *built* (layout/nav/footer construction) rather than for one decorative detail. Treat `real good` items as his highest-conviction references for structural/IA work specifically.
- **High-frequency tags name the vocabulary he thinks in** (`footer`, `layout`, `colors`, `hero`, `typography`, `features`, `menu`, `scrolling-animation`, `navigation` are the top 9) — when proposing references unprompted, reach for these categories first since they're demonstrably what he's building a mental library of, not tags I'd guess matter.
- Co-occurrence beyond the generic trio is itself a finding: `features`+`hero` (26), `grids`+`typography` (17) — these pairings suggest he notices typography specifically *inside* grid layouts, and features sections specifically as *part of* hero composition, not as separate concerns.

## Cross-check against existing product DS

The dark-bg-plus-one-accent pattern and oversized bold headline are already load-bearing in Fadercraft's shipped DS (`#0f1017` bg-dark, mint/lavender/amber semantic accents, `Heading/Hero` 48/Bold DM Sans — see main `MEMORY.md`) and in Bifi's dark-card DS. That's not coincidence — it's this same taste already expressed in both products. Read this file as confirming/refining that direction on new screens, not introducing a new one.

## When to pull the full index

For a concrete task ("show me references for a pricing section", "what do footers I like look like") — open `tag-index.md` and pull matching entries; several have live URLs worth a quick WebFetch/screenshot look before designing. Don't dump the whole index into context for micro/small tasks — this file's summary is enough for those.
