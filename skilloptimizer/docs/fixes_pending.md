## Реализация — фикс №5

Отложить схлопывание поля на ~1.2с после показа «Saved», та же механика, что уже используется для
error-текста (ветка `catch` не трогает `isAdding`, поэтому ошибка и так остаётся видимой):
```swift
private func save() {
    let value = text.trimmingCharacters(in: .whitespacesAndNewlines)
    do {
        try onSave(value)
        status = "Saved"
        text = ""
        onSaved()
        DispatchQueue.main.asyncAfter(deadline: .now() + 1.2) {
            isAdding = false
            status = nil
        }
    } catch {
        status = "Error: \(error.localizedDescription)"
    }
}
```

## Реализация — фикс №2

Переиспользует уже существующий в этом же файле паттерн `isConfirmingDelete` (у Delete Skill), на уровне
отдельной фразы:
```swift
@State private var confirmingPhrase: String? = nil

// в строке фразы, вместо мгновенного xmark.circle.fill:
if confirmingPhrase == phrase {
    HStack(spacing: 4) {
        Button { confirmingPhrase = nil } label: { Image(systemName: "xmark") }
            .buttonStyle(.plain).foregroundStyle(.secondary)
        Button {
            try? SkillFileEditor.removeTriggerPhrase(phrase, from: path)
            onTriggersSaved()
            confirmingPhrase = nil
        } label: { Image(systemName: "checkmark.circle.fill") }
            .buttonStyle(.plain).foregroundStyle(.red)
    }
} else {
    Button { confirmingPhrase = phrase } label: {
        Image(systemName: "xmark.circle.fill")...
    }
}
```

**Альтернатива** (дороже в реализации, меньше трения): toast «Removed "X" · Undo» на несколько секунд вместо
confirm-до-действия — требует хранить снятую фразу для отката.
