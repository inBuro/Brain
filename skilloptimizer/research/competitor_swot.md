# SWOT по конкурентам — в контексте Skill Optimizer

## WakaTime

- **Strengths:** 10+ лет истории, 50+ IDE-интеграций, огромный охват данных, свежий AI-дашборд (adoption/spend/AI-vs-human ratio) для Claude Code/Cursor/Copilot.
- **Weaknesses:** нет menu bar приложения — только веб-дашборд; все AI-метрики только на платном Premium ($14/мес); порог входа выше, чем у ambient-инструментов.
- **Opportunities (для нас):** WakaTime смотрит на *время и объём кода*, не на *содержание инструкций* — ниша «какие именно skills/промпты реально работают» остаётся свободной даже при их AI-дашборде.
- **Threats (для нас):** зрелая база пользователей и бренд в разработческом сообществе; если WakaTime решит углубиться в анализ конкретных AI-инструкций, догнать их охват данных будет сложно.

## AgentPeek

- **Strengths:** единственный прямой аналог по форм-фактору (нативный macOS menu bar, Apple Silicon), нулевое трение онбординга (без API-ключей), охватывает 22+ AI-агента включая Claude Code.
- **Weaknesses:** фокус только на токенах/лимитах, не на содержании — не показывает, какие конкретно инструкции/skills используются; цены не публичны, что снижает доверие; только Apple Silicon (macOS 14+).
- **Opportunities (для нас):** ближайший конкурент по форм-фактору, но не по содержанию — Skill Optimizer может занять соседнюю полку «то же место в menu bar, другой слой данных» без прямого столкновения.
- **Threats (для нас):** если AgentPeek расширится с токенов на «что вызывалось» (естественное направление роста для них), станет прямым конкурентом с уже готовой аудиторией и UX-паттерном.

## Rize

- **Strengths:** сильный UX реального времени (coaching, focus score, цветовое кодирование), зрелый и красивый дизайн, кросс-платформенность (macOS + Windows).
- **Weaknesses:** не developer-специфичен, не видит содержимое AI-инструментов вообще (только «открыто окно Cursor», не что в нём происходило); нет free tier.
- **Opportunities (для нас):** Rize задаёт стандарт «мотивационной абстракции» (score, цвет) — паттерн можно позаимствовать для собственной метрики без конкуренции за аудиторию (у Rize она шире, не Claude Code-специфична).
- **Threats (для нас):** низкие, разные аудитории и разный слой данных — Rize не претендует на нишу skill-observability.

## Timing

- **Strengths:** полностью автоматический трекинг без ручных действий, 10-летняя зрелость, разумная цена ($7/мес), AI-сводки дня.
- **Weaknesses:** нет developer-специфичных фич, нет трекинга AI-инструментов вообще, аудитория — фрилансеры/агентства для биллинга клиентов, а не разработчики.
- **Opportunities (для нас):** демонстрирует, что «полная автоматичность без таймеров» — ожидаемый пользователями стандарт для menu bar трекера; Skill Optimizer уже это делает (пассивный скан транскриптов).
- **Threats (для нас):** минимальные — Timing нацелен на другую аудиторию и не показывает признаков движения в сторону AI/dev-специфики.

## Faros AI

- **Strengths:** глубокая enterprise-интеграция (100+ SDLC-инструментов), связывает AI usage с бизнес-метриками (PR velocity, code quality), решает реальную боль CTO — «что нам дают эти AI-подписки».
- **Weaknesses:** enterprise pricing и сложность внедрения, полностью недоступен и нерелевантен для одного разработчика.
- **Opportunities (для нас):** подтверждает, что вопрос «AI tool ROI/observability» уже монетизируется на другом конце рынка — валидирует нишу в целом, не создавая прямой конкуренции для персонального инструмента.
- **Threats (для нас):** нет прямой угрозы на горизонте текущего масштаба Skill Optimizer; риск появляется только если Faros (или аналог) выпустит облегчённую версию для индивидуальных разработчиков.

## Langfuse

- **Strengths:** Prompt Registry с версионированием и метками dev/prod — архитектурно ближайшая параллель к «именованным, версионируемым инструкциям, подтягиваемым по ситуации», зрелый open-source проект (приобретён ClickHouse), self-host бесплатно.
- **Weaknesses:** работает только на уровне явных SDK-вызовов LLM — не видит ambient-инструкции окружения, если они не обёрнуты в API-запрос; требует интеграции в код приложения, не «сканирует» готовую среду как Skill Optimizer.
- **Opportunities (для нас):** доказывает, что паттерн «registry с версиями и метками» востребован у разработчиков — можно позаимствовать саму идею версионирования триггеров без конкуренции (Langfuse работает на другом уровне стека).
- **Threats (для нас):** низкие — разный слой анализа (application prompts vs assistant instruction files), пересечение аудитории маловероятно в обозримом будущем.

## PromptLayer

- **Strengths:** акцент на редактирование промптов нетехническими пользователями прямо в UI, visual diff между версиями — прямая параллель к задаче Skill Optimizer «править триггеры без похода в файл»; пережил консолидацию рынка (Humanloop, Helicone-как-отдельный-продукт, PromptHub закрылись/поглощены), остаётся устойчивым.
- **Weaknesses:** требует SDK-интеграции и настройки; работает на уровне application-промптов, не видит инструкции самого AI-ассистента; free tier узкий (2 500 req/мес).
- **Opportunities (для нас):** подтверждает спрос на in-UI редактирование инструкций нетехническим способом — валидирует именно ту фичу Skill Optimizer, которой нет ни у одного из пяти конкурентов первого захода.
- **Threats (для нас):** минимальные — целится в команды, встраивающие LLM в свой продукт, а не в персональных power-users ассистентов.

## Knip

- **Strengths:** де-факто стандарт dead-code detection в JS/TS (40M скачиваний/мес, Adobe/Shopify/Microsoft/Vercel), полностью open-source и бесплатен, механика scan → report → `--fix` — почти буквальный аналог механики Skill Optimizer.
- **Weaknesses:** нет GUI вообще — только CLI и текстовый отчёт; нет понятия «архивировать» — только «удалить», что менее безопасно, чем перенос в `_archive/` у Skill Optimizer; нет интерактивного action layer (нельзя точечно отредактировать найденный артефакт, только удалить/оставить).
- **Opportunities (для нас):** самый близкий по механике аналог во всём исследовании — подтверждает, что «dead code detection для instruction layer» не гипотетическая ниша, а рабочий паттерн, уже доказавший спрос (40M скачиваний/мес) в соседнем домене. Skill Optimizer добавляет то, чего нет у Knip: GUI, архивацию вместо удаления, интерактивное редактирование.
- **Threats (для нас):** практически нулевые — Knip и Skill Optimizer работают в непересекающихся доменах (код vs AI-инструкции ассистента), но сам факт существования зрелого паттерна означает, что при масштабировании идеи стоит переиспользовать его safe-by-default подход (report-only → explicit `--fix`).
