# User flow — Skill Optimizer

Основной сценарий, пройденный для аудита (см. `screenshots/01_main_list.png` для шага 1; шаги 2-4 верифицированы по исходному коду — `SkillDensityMenu.swift`, `DescriptionPopover.swift` — и по прямому наблюдению во время тестирования этой сессии, скриншоты которого не сохранились из-за особенности автоматизированного клика, см. оговорку в `audit_report.md`).

1. **Открытие мунбара.** Клик по иконке `chart.bar.fill` в строке меню → открывается попап (300pt шириной, высота по контенту, до 740pt с прокруткой).
2. **Просмотр списка.** Сверху — переключатель таймфрейма (24 hours / Week / Month) и кнопка сортировки (`321` / `ABC`). Ниже — список: роутеры сверху, подскиллы с отступом 16pt под ними. У каждой строки — серый счётчик total и, если есть недавняя активность, зелёный `+N`.
3. **Открытие описания скилла.** Клик по имени скилла (со стрелкой `›`) → открывает `.popover` с описанием, триггерами и слэш-командами этого скилла.
4. **Редактирование триггеров.** В попапе описания — клик «Edit» разворачивает список триггеров с крестиком у каждого (удаление); «+ Text-trigger» / «+ /trigger» — раскрывающиеся поля добавления.
5. **Архивация скилла.** В правом верхнем углу попапа описания — «Delete Skill» → двухфазное подтверждение («Delete? / Confirm / Cancel»).
6. **Подтверждение активности.** Клик по зелёному `+N` → счётчик гаснет (acknowledge).
7. **Ручной рефреш / выход.** Внизу — «Updated: HH:mm:ss» (кликабельно, рефреш) слева, «⌘Q Quit» справа.
