## Монетизация и дистрибуция (решения о скоупе, не UI-фичи)

| Решение | Описание | Источник |
|---|---|---|
| Free = просмотр, Paid = действия (правка/архивация) | Граница монетизации по функциям, не по объёму данных | Персона 1 инсайт 2 (интервью library_architect); Персона 3 инсайт 3; `deep_research_results.md` рекомендация Freemium+PRO $14.99 |
| Разовая покупка, не подписка | Подтверждено дважды в интервью, совпадает с рыночным паттерном | Интервью library_architect; `deep_research_results.md` §4 |
| Два канала: Homebrew (полная функциональность) + App Store (урезанная, sandbox) | Архитектурное противоречие sandbox vs прямая запись в файлы | brief.md §7; интервью library_architect (персона сама подняла) |
| Кросс-платформенная поддержка SKILL.md (Codex CLI, Gemini CLI, Cursor) | Формат уже мультиплатформенный — расширение аудитории без смены движка | `deep_research_results.md` Implication 4 |

## Не фичи, а открытые технические вопросы (перенесены в риски PRD)

- Подхватывает ли активная сессия Claude Code правку `SKILL.md` «на лету» — не проверено, влияет на приоритет нескольких фич выше.
