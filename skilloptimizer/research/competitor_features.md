## Фичи, уникальные для плана Skill Optimizer

Ни у одного из восьми конкурентов нет одновременно всех трёх:

- Просмотра **содержательных триггеров** конкретной инструкции/skill (что именно вызывает срабатывание) — у Langfuse/PromptLayer/Knip есть частичный аналог (версии промпта / usage refs), но не в формате «условие срабатывания».
- **Редактирования триггеров прямо из UI** с немедленной записью в реальный конфигурационный файл — Langfuse и PromptLayer это умеют, но только для application-промптов, не для инструкций самого AI-ассистента; Knip вообще не даёт интерактивного редактирования.
- **Архивации неиспользуемого элемента одной кнопкой** с возможностью отката (не безвозвратное удаление) — даже у ближайшего механически аналога (Knip) есть только удаление, без архивации.

Это подтверждает и уточняет вывод из `competitive_analysis.md`: рынок либо наблюдает за *количеством* использования AI-инструментов (время, токены, PR — WakaTime/AgentPeek/Faros), либо даёт content-level инструменты для *application-уровня* промптов (Langfuse/PromptLayer), либо решает ту же механическую задачу для кода (Knip) — но ни один не соединяет все три слоя: ambient-инструкции конкретного AI-ассистента + content-level видимость + safe archive-действие из UI. Это и есть точная ниша Skill Optimizer.
