# UX-паттерны конкурентов

## 1. Рыночный стандарт (что делают все одинаково)

- **Полная автоматичность.** Ни один из пяти конкурентов не требует от пользователя нажимать «старт/стоп» или логировать активность вручную — данные собираются пассивно в фоне (Timing, Rize, AgentPeek, WakaTime через IDE-плагин). Это ожидание уже сформировано у аудитории menu bar трекеров.
- **Разбивка по времени.** День/неделя/месяц (или их аналоги) — стандартный набор таймфреймов у всех пяти.
- **Компактный menu bar popover как основной UI** — у трёх из пяти (AgentPeek, Rize, Timing), где приложение живёт именно в строке меню, а не открывает отдельное окно/веб-страницу по умолчанию.
- **Freemium или free trial как модель входа** — у четырёх из пяти (кроме Rize) есть либо бесплатный тир, либо триал, прежде чем просить оплату.

## 2. Точки расхождения

- **Глубина онбординга.** AgentPeek и Timing — нулевое трение (открыл — работает). WakaTime требует установки плагина в каждый редактор. Faros AI — тяжёлый enterprise-онбординг с demo-звонком.
- **Мотивационная абстракция.** Rize строит вокруг daily focus score (0–100) и цветового кодирования; WakaTime и AgentPeek — вокруг сырых чисел (часы, токены) без верхнеуровневой метрики-«самочувствия»; Timing — вокруг таймшитов для биллинга.
- **Где живут данные.** WakaTime и Faros AI выносят основной интерфейс в веб-дашборд (menu bar/плагин — только сборщик данных); AgentPeek, Rize, Timing держат весь опыт в native menu bar UI.
- **Уровень детализации против уровня действия.** AgentPeek даёт много цифр (токены, лимиты, история), но не даёт никакого действия из UI. Rize даёт мало цифр, но подталкивает к действию в моменте (уведомление о дистракции). Ни один не даёт возможность *отредактировать конфигурацию* прямо из интерфейса.

## 3. Рекомендации — что взять и у кого

- **У AgentPeek** — паттерн «нулевое трение: приложение читает уже существующие системные файлы, ключи не нужны». Skill Optimizer уже следует этому паттерну (чтение локальных транскриптов) — стоит явно закрепить и не размывать будущими фичами, требующими настройки.
- **У Timing** — «никаких ручных таймеров, весь автозапуск через launchd» уже реализовано; сохранить эту философию при добавлении новых фич (не вводить кнопки типа «начать отслеживание X»).
- **У Rize** — цветовое кодирование/скоринг как мотивационная надстройка над сырыми числами. Применимо: вместо (или в дополнение к) счётчику вызовов ввести лёгкую визуальную метрику «здоровья» библиотеки скиллов (например, доля активных за последний месяц), не превращая это в геймификацию с очками.
- **У WakaTime** — сопоставление двух режимов использования («AI-generated vs human-written») как формат инсайта. Применимо: «вызван автоматически по тексту vs вызван вручную через /command» — у Skill Optimizer уже есть данные для этого разреза (слэш-команды vs текстовые триггеры), но UI пока не visualisирует именно это сравнение.
- **У Knip (добавлено 2026-08-29)** — safe-by-default цикл «report-only по умолчанию → явное действие (`--fix`) только по запросу», плюс группировка отчёта по типу проблемы. Skill Optimizer уже частично следует этому (архивация требует подтверждения), но группировка результатов по типу («неиспользуемые совсем» vs «редко используемые» vs «дубли триггеров») пока не реализована — потенциальное развитие.
- **У PromptLayer (добавлено 2026-08-29)** — редактирование контента нетехническим пользователем прямо в UI, с visual diff между версиями. Skill Optimizer уже даёт in-UI редактирование триггеров; чего пока нет — истории изменений/диффа перед сохранением, что PromptLayer делает штатно.
- **У Langfuse (добавлено 2026-08-29)** — паттерн registry с метками (dev/prod) для версий одной и той же именованной сущности. Менее применимо напрямую (у Skill Optimizer нет концепции «окружений»), но сама идея явного версионирования триггеров при правке — направление для будущего (сейчас правка перезаписывает `description:` без истории).
- **Не брать ни у кого:** ни один из восьми конкурентов не даёт полный цикл «увидеть содержание → отредактировать → архивировать с откатом» в одном интерфейсе — здесь Skill Optimizer первопроходец, паттерн синтезирован из кусков разных категорий (Knip даёт detection-цикл, PromptLayer — in-UI редактирование, ни один — архивацию с откатом).
