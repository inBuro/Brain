## Открыто

1. **Стилистический ход под 9:16 — не сделан.** Владелец поставил задачу: кадр не обязан занимать
   всю доступную ширину; нужен приём, который превращает вертикальный формат из ограничения в
   позиционирование («стильный, необычный продукт»). Направления не сформулированы — работа не начата.
2. **Вторая строка секции `Problem`.** Можно заменить на конкретный момент из направления A
   («You wrote the trigger. You used the phrase. Claude solved it from scratch anyway.»). Сильнее по
   узнаванию, но сдвигает секцию с «нет прибора» на «сломался триггер» — territория `Features`.
   Решать на живом макете. Детали — `copy/problem-section-directions.md`.
3. **Блок лицензии и установки — не начат.** Владелец просил перенести с существующего сайта
   конструкцию «скачать серийный номер для полной лицензии» + кнопки установки (Homebrew / командная
   строка), и повторить паттерн установки в футере. **Донор не подтверждён:** владелец назвал Bifi,
   но `~/Brain/Bifi/` — это проект по дизайн-системе Beefy Finance, 19 файлов, все markdown, никакого
   HTML и ничего про лицензии. По описанию паттерн совпадает с Fadercraft, который
   `ia/screens-inventory.md` и так называет структурным донором. Уточнить до начала работы.
4. **Регрессия: белое пространство под футером.** Заявлена владельцем, воспроизводится на его машине.
   В этой сессии не диагностирована — кода сайта в репозитории нет. Ловится локально через
   `git diff <последний рабочий коммит>..HEAD -- '*.css'`.

## Что блокирует работу по коду

Кода сайта в `~/Brain` нет: ни `package.json`, ни `.tsx/.jsx/.vue/.svelte`, из HTML только
`fadercraft/groove mix/sidepanel.html` и `demo-video-titles.html` — это не страницы сайта.
`site/` содержит только ресёрч, IA, копирайт и визуальные правила.

Пока сайт не заведён в git, удалённая сессия может делать по нему только документы и копирайт.
Правки в разметку и стили требуют, чтобы проект был запушен и подключён в сессию.
