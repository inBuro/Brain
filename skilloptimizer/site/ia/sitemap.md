# Skill Optimizer — сайт продукta: sitemap

> Лендинг-адаптация `directive_prd_to_sitemap.md`: линейная структура секций страницы вместо дерева экранов.
> Структура страниц сайта в целом — по образцу существующего Fadercraft (`~/Projects/Projects/fadercraft`):
> одна продуктовая страница с якорными секциями + отдельные `Privacy` и `Updates`, общий `404`.

## Страницы сайта

```
Home (/) — лендинг с якорными секциями                                    [core]
  Hero          — «Skill Optimizer for Claude Code» + боль в одну строку + CTA Install          [core]
  Problem       — библиотека собрана осознанно, но её работу не видно (направление B)             [core]
  HowItWorks    — цепочка: наблюдение → диагностика → правка → чистка                            [core]
  Features      — 4 карточки той же цепочки, развёрнуто                                          [core]
  Privacy       — тизер «100% Local-First, ноль сети, ноль телеметрии» + ссылка на /privacy       [core]
  Differentiation — позиционирование по категориям, без имён конкурентов                          [core]
  Pricing       — Free (просмотр/диагностика) vs Paid (правка+архивация, разовая покупка)         [core]
  Install       — Homebrew-команда, требование macOS 13+                                          [core]
  FAQ           — снятие возражений (приватность, формат данных, платформа)                       [core]
  Footer        — ссылки, контакт                                                                 [core]

Privacy (/privacy)             — детальный разворот приватности: что не собирается, как проверить [core]
Updates (/updates)             — changelog по версиям, по образцу Fadercraft *-updates.html        [core]
Download (/download)           — подтверждение после клика Install, следующий шаг                 [core]
404                            — базовая гигиена                                                  [core]
```

MECE-проверка: каждая секция/страница закрывает ровно одну тему, разделы не пересекаются. Глубина — 2 уровня (страница → секция), в пределах правила ≤3.

## Приоритеты

Всё `[core]` — сайт для v1.0 публичного релиза, PRD не описывает v2/later-контент для маркетингового сайта отдельно от самого продукта (roadmap v1.1/v2.0 в PRD §9 — про фичи приложения, не про сайт).
