## Что есть в нашем плане, но нет ни у одного конкурента разом

Ни один по отдельности не уникален — AgentPeek уже закрывает «local-first секция + разовая покупка + changelog».
Уникальна **комбинация**: у AgentPeek нет конкретного заявления вида «не отправляет X/Y/Z» **применительно к
контенту скиллов** (у них это про код/промпты агента, у нас — про содержимое `SKILL.md` и `.jsonl`-транскрипты) —
и ни у кого из восьми нет одновременно (разовая покупка + explicit local-claim + changelog + FAQ). Это не новая
фича сайта, а то, что этот набор целиком не встречается ни у кого — само по себе слабый дифференциатор, если
не подкреплён реальным продуктовым отличием (в PRD §4 такое отличие есть на уровне продукта: content-level
видимость + safe-правка с откатом — сайт должен доносить именно это, не просто «мы тоже locally-first»).

## Главный пробел

Строка «Социальное доказательство» — единственная, где у всех восьми конкурентов ✅/⚠️, а у нас реалистично ❌
на день релиза (нет пользователей, PRD §2 прямо говорит «рабочая гипотеза, нет исторических данных»). Это не
недоработка ресёрча — это честное состояние продукта на v1.0, решение по этому пункту — задача Scope-приоритизации
следующего шага (skip секции на v1.0, placeholder, или альтернативная форма доказательства — например открытость
самого кода/README вместо отзывов, по аналогии с паттерном Knip).
